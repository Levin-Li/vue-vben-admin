# 页面展示设置记录信息

超级管理员通过 CRUD 页面工具栏的“页面展示设置”或“展示设置2”打开抽屉。设置 1 打开时不会重新请求适配配置，点击“加载设置”才执行加载；设置 2 保持既有打开行为。

加载成功后，抽屉标题栏显示实际适配记录的设置 ID、名称、最后更新时间。加载开始、失败或无匹配时清除旧信息。缺失字段显示短横线，长值保持单行并通过悬停查看完整内容。

上传根据当前范围选择新建或更新，成功后按实际保存 ID 回查记录并替换标题信息。这条记录可能不同于当前用户适配配置，标题信息不改变页面的运行时匹配规则。上传失败保留原信息；写入成功但回查失败时提示并将更新时间显示为短横线，不显示旧时间。

验证方式：打开设置 1，点击加载后观察标题；调整上传范围并成功保存后，核对标题 ID 与实际保存记录一致。上传会修改服务器记录，仅在有权限且确认范围后操作。
