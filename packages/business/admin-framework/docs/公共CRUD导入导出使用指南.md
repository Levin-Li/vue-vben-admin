# 公共 CRUD 导入导出使用指南

## 入口与前置条件

使用本包公共 CRUD 页面时，导出按钮位于列表右上角工具区。导出沿用当前激活列表的查询条件、排序、读取权限和字段组授权；页面上的当前页码不决定导出范围。匹配记录超过 50,000 条时，页面会提示缩小查询范围，且不会开始下载。

导入按钮仅在页面 API 服务提供 `batchCreate` 方法、当前用户有对应操作权限时显示。导入是写操作；使用前应确认目标租户、页面归属和导入字段的权限。单纯能打开导出弹窗不代表具备导入权限。

## 导出步骤与结果

1. 在目标列表设置查询条件和排序，点击工具区“导出”。多列表页面先切换到需要导出的列表；每个列表使用自己的查询、排序和字段设置。
2. 在字段弹窗勾选列，可修改 Excel 列标题并用上下按钮调整顺序。默认勾选当前表格可见列；查询专用字段默认不成为导出列，页面显式配置的例外除外。
3. 确认后，页面从第一页读取该条件下的全部匹配记录，生成真正的 `.xlsx` Excel 工作簿并下载。服务端即使将请求的每页 2000 条裁为较小页，页面也会继续读后续页；记录的显示文本、布尔值和选项标签尽量与列表一致，编号保留为文本。成功后当前列表刷新，原分页位置不因导出翻页改变。

列表接口失效、权限变化、分页未推进或下载失败时，页面提示导出失败，不交付伪完整的文件。普通页码分页在持续写入的列表上不构成数据库快照；需要严格时间点一致性的业务应另行提供服务端快照导出。

## 导入步骤与结果

在具备批量新增权限的页面点击“导入”，选择 `.csv`、`.xls`、`.xlsx`、`.xml` 或 `.html` 文件。新导出的 `.xlsx` 可直接选择；旧版本导出的 XML 内容 `.xls` 仍可读取，单元格中有逗号时也按 XML 处理。核对文件列与目标字段映射、必填字段、默认值和预览错误后确认。页面每批提交最多 2000 条；可请求在当前批次完成后停止，成功批次会保留并刷新列表。映射或转换错误会阻止提交，后端批量新增失败会显示错误和导入控制台。导入不承诺跨批次整体回滚。

最小核验：用两个以上列表页的测试数据导出，确认下载文件为 `.xlsx`，并在 macOS Numbers 实际打开，核对工作表、列标题及数据行数等于当前查询结果总数；再在隔离环境导入一条合法记录，核对列表刷新及数据库归属。仅验证 ZIP 或 XML 结构不能替代 Numbers 打开。导入字段、业务唯一性与越权拒绝仍由具体业务 API 判定，不由文件映射替代。
