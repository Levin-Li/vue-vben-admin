# 标准 CRUD 金额展示使用说明

## 适用范围

标准 `CrudPage` 的列表和详情对金额类数值字段默认使用四位分组及“元”单位。以 `1234567890.12` 为例，正文显示 `12,3456,7890.12元`，悬停提示显示 `12亿3456万7890.12元`。小于一万元时不显示重复提示。

字段须声明 `type: 'number'` 或 `valueType: 'number'`。框架按 `amount`、`balance`、`price`、`fee` 等键名或“金额”“余额”“价格”“费用”“额度”等标题识别金额；费率、汇率、比率和百分比不作为金额。业务语义不符合默认识别时，在字段附近使用 `moneyDisplay.money` 明确指定。

## 页面字段配置

```ts
{
  key: 'totalAmount',
  label: '总金额',
  type: 'number',
  moneyDisplay: {
    unit: '美元',
    grouping: 'three',
    chineseUnitTooltip: false,
  },
}
```

- `unit`：默认“元”；可设为“美元”等业务单位，显式空字符串表示不展示单位。
- `grouping`：`four` 为四位分组（默认），`three` 为三位分组，`none` 为不分组。
- `chineseUnitTooltip`：默认显示中文数量级提示；设为 `false` 可关闭。
- `money`：设为 `true` 可将未被识别的数值字段声明为金额，设为 `false` 可排除误识别字段。

覆盖仅作用于该字段所在页面的列表和详情。查询、新增、编辑输入与提交值保持原样；导出沿用既有导出格式和转换器。展示不代表服务端金额单位转换，也不改变字段的接口权限。

当同一列表的每条记录可能使用不同币种时，字段配置 `unit: ''`，并保留独立的货币代码或币种列；不要把这类金额统一标为“元”。

## 最小验证

打开包含金额字段的标准 CRUD 页面，确认列表与详情显示四位分组和单位，悬停提示显示中文数量级；再检查新增或编辑表单中的输入值及提交请求仍为原始数值。页面配置覆盖后，复查该字段正文及提示，其它字段应保持公共默认。
