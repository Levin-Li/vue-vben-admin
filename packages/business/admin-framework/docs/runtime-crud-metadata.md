# 动态 CRUD 页（DynamicCrudPage）

## 入口与前置条件

静态 API 页面在开发期注册接口字段契约，运行时模型页面可读取模型专属的服务端授权元数据；两者都构建 `CrudPageConfig` 并渲染公共组件：

```ts
import DynamicCrudPage from '@levin/admin-framework/framework-commons/shared/dynamic-crud-page.vue';
import type { CrudPageConfig } from '@levin/admin-framework/framework-commons/shared/types';
```

定义页、业务列表和运行时模型可以共用这一渲染器。宿主提供真实 API、字段、动作权限及数据属性策略；查询、工具栏、列表、表单、详情和界面展示设置由公共页处理。动态元数据不能被当作执行脚本或 SQL。

## 配置与服务协议

`apiService.list(params)` 返回 `{ items, totals }`。适配后端的页码、每页上限与 `total` 名称，并保持当前查询和排序；公共列表与跨页导出使用同一个回调。未配置 `listPath` 或列表专属路径时走该服务回调，显式路径仍沿用既有 HTTP 分支。导出固定开始时的查询与排序快照，包括末次空页与下载前也会校验权限代际。

`apiService.create/update` 接收公共页已经过字段策略、UI 设置、校验和提交范围处理的值。宿主可在回调内转换成真实 API 的 `values/scope/expectedVersion` 等载荷；不得把已排除字段或未经允许的旧记录值补回。`apiService.retrieve` 返回独立详情契约。

`apiService.delete(params, options, record)` 的第三个可选参数是用户读取的原记录，供动态服务取乐观锁；第二个参数保留原有请求选项语义。默认删除参数继续只有主键，不会自动把整条记录发给 HTTP 端点。版本冲突由后端拒绝，不允许自动换新版本重放。

`allowQuery: false` 明确表示没有可执行查询接口，会阻止查询 UI、列表请求及对应策略加载，即使当前账号具有通配授权。它与其它动作可用性配置一样，不可用权限表达式占位符替代。

## 异步表单上下文

- `prepareCreate()` 可异步加载当前身份的创建字段、候选及默认值，返回默认值对象或不返回值。准备失败不会打开表单。
- `loadEditRecord(record)` 可异步取得完整 EDIT 响应，返回对象替代列表行。列表字段与编辑字段不同时，不能把列表行合并进去恢复未授权字段。普通编辑与单 JSON 字段编辑都使用此入口。
- 准备过程可更新配置字段与策略上下文。公共页在准备后重新取得对应操作策略，再初始化表单；真实主体、权限、页面或归属变化使旧异步结果失效。
- 组件公开 `reload()`、`openCreate()` 与只读 `isFormOpen()`。对象级自定义动作可复用标准新增表单，但宿主必须先确定该动作的字段和权限；表单已打开时不得切换其业务目标。仅打开表单的动作应关闭提前成功提示和列表刷新，实际保存成功后由公共表单反馈。`createButtonVisible: false` 只收紧内置新增按钮显示，不授予表单或接口权限。

## 静态 API 与运行时模型字段策略

普通 API 不通过 HTTP 查询字段策略或全量快照。所属模块注册 `registerDataAttrStaticContract({ version: 1, policies: [...] })`，认证流程用既有 `userInfo` 中的有效许可执行 `initializeDataAttrFieldGrants({ version: 1, allowed: [{ operation, groupKeys }] })`。公共 CRUD 按实际方法/路径定位接口，再本地合并许可；具体开发接入见[API 属性组授权接入指南](api-attribute-group-permissions.md#api-开发期静态声明)。

身份就绪但缺少静态声明时，前端默认不限制字段，仅在控制台按会话和接口去重警告；后端仍重新检查实际请求。已声明无许可的受控组必须拒绝，非法或歧义声明和未就绪身份不能套用缺失默认。页面调用其它实体接口时使用其独立声明，表单视觉分组不等于权限分组。

`dataAttrPolicyProvider(operation)` 是可选的运行时策略来源，返回合法的 `DataAttrPolicy`。显式配置后，提供者失败即拒绝，不会回退到旧宿主模式或关闭属性策略。

提供者应消费服务端按模型、动作和当前主体裁剪的字段契约。编译策略时，应对配置字段全集的请求与响应分别明确允许/拒绝；不能只列允许字段并假定未知路径会拒绝。服务端未授权字段不得进入客户端字段配置或记录缓存。共享 HTTP 网关路径不能代替模型专属字段组身份。后端仍须逐次校验动作、字段组、可信记录范围和版本。

模型标识、主体、有效权限或归属变化后，宿主应更新配置/策略身份并重新读取该模型元数据；这不允许重新引入通用 API 字段策略或快照 HTTP 查询。旧在途策略和导出结果不能跨上下文回填。

## 展示设置与默认值

`pageDisplaySettingCode` 可以指定稳定设置编码。多个模型共用同一路径或仅通过查询参数区分时，应按稳定模型标识隔离编码，不依赖菜单 ID。显式设置该编码时，本地列显隐、顺序和固定偏好也使用该模型命名空间；未设置时保留静态页面原存储键。

字段可声明 `defaultHidden`，分别指定 `create/edit/detail/query/list` 默认隐藏状态；也可声明 `defaultVisibleRoleCodes`。运行时及设置抽屉使用相同默认，已经明确保存的 UI 设置优先。字段仍保留在已授权候选清单中；`form: false/search: false/table: false` 表示不属于该用途，不能用来替代可配置的默认隐藏。

默认可见角色是展示约束，不是授权。后端已裁剪的运行时字段可明确提供空角色数组，继续由动作及属性策略决定资格。UI 设置不能恢复策略拒绝的字段。

公共 UI 设置解析器缓存也按登录主体及归属上下文隔离，采用短时有界缓存与请求合并；刷新、替换或主体变化后旧响应不能回填。缓存返回值独立复制，页面修改不会污染下一次读取。

## 精度与最小验证

金融金额、精确小数和大整数使用文本及字符串值，避免经 `Number` 或普通数字输入转换。日期时间和时间适配器应保留未修改原始精度，真实修改和清空则按接口语义转换。

最小验证包括：列表和导出调用同一服务；创建默认值与失败保留；EDIT-only 字段和最新版本；只读字段显式展示而不提交；同一路径的模型设置隔离；权限切换拒绝旧响应；默认删除仍只发主键，自定义回调正确取得原记录版本。未使用这些可选扩展的静态页面沿用原契约。

只读布尔字段不会渲染列表快捷开关，事件入口也拒绝旧控件的写入。已有可写布尔字段仍遵循公共快捷更新行为。查询配置可用 `initialQuery: {}` 明确初始条件，使重置保留当前列表与展开状态并等待显式查询。

标准页面的代码元数据和领域模型的后端元数据都进入同一个 `DynamicCrudPage`。除元数据来源外，功能、操作、布局、展示设置、校验和权限规则统一使用公共实现；本次直接移除旧组件名称及旧公共文件路径，消费者须更新到 `framework-commons/shared/dynamic-crud-page.vue`，无旧入口转发。
