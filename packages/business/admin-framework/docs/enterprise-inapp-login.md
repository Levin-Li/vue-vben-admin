# 企业 App 内网页免登集成指南

## 前置条件与入口

后台 User 的企业登录配置必须启用 enable 与 enableInAppLogin，并关联当前租户的独立公司根。飞书、企微登记独立 inAppRedirectUri；钉钉填写真实企业 corpId。Secret 只由服务端 env 引用提供，前端公开应用上下文只包含允许公开的 Client ID/Corp ID 等必要信息。供应商参数与平台侧操作见 [Oak 插件配置指南](../../oak-base-admin/docs/enterprise-login-guidance.md)（多包源码阅读入口；安装后从 @levin/oak-base-admin 文档访问）。

群机器人消息链接指向受控站点的业务地址。未登录时登录入口识别飞书、企微或钉钉容器，通过对应平台授权桥接取得短效 code，交由后端核验并兑换本系统会话；完成后回到原业务地址，页面仍受本地权限约束。外部浏览器沿用普通登录。已有有效会话不被自动切换。

## 权限与错误语义

容器标识和消息链接不是登录凭证。后端必须校验用途、浏览器事务、租户、公司、state、有效期及一次性消费，不能以手机号、姓名或邮箱代替稳定企业身份。未绑定用户先以已有方式登录，再本人主动绑定。平台拒绝、客户端不支持桥接或域名/应用范围不合法时停止自动重试，保留普通登录入口。

基础免登不保证返回手机号，不强制申请敏感手机号权限。飞书 contact:user.phone:readonly、企微 snsapi_privateinfo 加 user_ticket/getuserdetail 手机字段权限、钉钉 Contact.User.mobile 是额外授权能力，不能等同基础身份核验。

## 最小验证

使用已获授权的真实企业应用及范围内测试员工，在三个 App 中分别从群消息打开业务链接。核对授权、已绑定成功、未绑定引导、原地址恢复、已有会话保护、拒绝后无循环；退出容器后普通浏览器应保持普通登录。需同时验证恶意跨租户/公司、重放和过期授权不能建会话。回环模拟和界面测试不替代真实容器验证。

## 回调绑定与兼容边界

飞书、企微的绑定回调 GET 不要求浏览器提供后台 Authorization。GET 校验浏览器事务、平台、租户及状态后桥接平台临时授权参数，不在该阶段核验成员身份或完成绑定。本地页先清理查询参数，再携带当前用户认证 Header，通过 POST 交换平台身份并校验发起属主、公司和绑定证明，最后兑换完成；不得把本地 JWT 加到 URL。应用配置指纹变化会拒绝尚未兑换的事务，创建端内事务受共享 Redis 租户配额限制。

已登录用户从右上角头像进入「个人中心」弹窗，选择「第三方账号绑定」及平台。默认宿主使用该弹窗入口；不得假设独立 `/profile` 路由已发布。绑定回跳沿用原业务地址，自动恢复弹窗及绑定页签；临时参数仅在内存中暂存最多三分钟，URL 清理、路由初始化或超时均不能使不同事务混用。

中间参数是平台一次性授权码，不是本地登录令牌。集成应用必须在 HTML 资源加载前声明 `no-referrer`，入口代理也设置 `Referrer-Policy: no-referrer`；桥接页不加载 URL 统计脚本，访问日志排除查询和 Referer。后端 302 的策略不能替代最终 HTML 策略。前端公开接口显式提交 returnUrl，不依赖 Referrer。

飞书端内采用官方 v3 token 协议及 SDK 用户信息读取。SDK 2.8.5 的 v3 token 方法在 JDK 25 存在 HashMap 私有字段反射兼容问题，因此仅该交换方法使用有界的固定官方 HTTP 适配，不引导添加全局 add-opens 参数。

钉钉官方脚本load后仍需等待`dd.ready`，只在原生桥接就绪后调用一次`requestAuthCode`。就绪及授权阶段各有十秒时限；缺少ready、SDK错误或超时安全失败，重复/迟到ready及code不覆盖已经完成的结果。模拟桥接也须异步触发ready并拒绝提前取码，不能以脚本加载替代真实原生初始化阶段。

部署后端属性 `enterprise.in-app.transactions-per-minute` 默认每租户每分钟 120，允许 1–10000，多个节点共享 Redis 限额；不可用或超限拒绝创建，前端应显示安全错误及普通登录入口，不循环授权或自行绕过。

## 平台名称显示

登录及个人中心绑定入口统一显示“飞书、企业微信、钉钉”。绑定卡片依据后端sourcePlatform识别来源，成员昵称单独显示；请求继续使用FEISHU、WECHAT_ENTERPRISE_V2、DINGTALK_V2和绑定ID。未知平台保留明确名称或来源编码，名称按文本渲染。
