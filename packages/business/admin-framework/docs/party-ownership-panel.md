# 绑定归属面板接入

归属描述可选 `orgTypes` 和 `orgCategories`；同时提供时，组织类型和类别都必须匹配，人员候选也限定在匹配的组织内。未提供类别时沿用原行为。组织目录缺失类别时不会推测，服务端仍须独立校验组织及人员范围。

`party-ownership-panel.vue` 展示调用方传入的归属组；每组根据当前授权数据决定字段可见性、写入能力和实际绑定或调整操作。调用方须从当前登录身份、准确的接口操作字段契约和实时授权结果计算 `canReadOrg`、`canReadUser`、`canWriteOrg`、`canWriteUser`、`canBind`、`canAdjust`，身份或授权变化时更新整个 groups。`bound` 必须由可信服务端依据实际数据确定，不能仅从被字段权限遮盖的值推断。

选择人员后面板从选择器返回的人员记录读取所属组织，自动带入组织；所选人员存在时组织选择锁定。清除人员后保留组织供调整。`collectChanges()` 一次收集并校验所有有变化的归属组；独立使用面板时，每项保存成功后应调用 `markCommitted(change)`，并在账号或记录切换时更新 `resetKey`。弹窗右下角提供“取消”和一个“确定”按钮，按组调用现有绑定或调整接口，并为每次请求使用递增后的记录版本。若某组失败，页面会说明已保存数量，保留尚未保存的草稿；这些请求不是一个跨组原子事务。该组件输出不是授权证明；服务端必须重新获取当前授权和成员组织，核验租户、对象范围、实体组与字段、绑定状态、版本和并发，不能信任前端传入的字段名、组织归属或布尔授权。

客户、供应伙伴、渠道伙伴、法律主体和结算单页面使用“绑定归属”入口。弹窗不显示独立组标题或外框，相邻组之间以分隔线区分，字段名称仍标明用途。实际可操作组以当前账号的接口和字段授权及记录状态为准；可在弹窗修改多个组，点击一次确定后核对结果。
