# 网页 Agent 使用与扩展指南

## 功能设计

管理后台登录后的全局布局提供可收展聊天窗。它是系统原生的 Agent 入口：模型负责理解任务，前端编排器只允许调用由业务模块显式登记的技能。当前路由不会决定权限，也不会自动把页面按钮或任意 HTTP 方法变成技能。

业务模块可登记只读技能和经预览的普通写入技能。模型返回的技能名、参数与业务数据均按不可信输入处理；权限、租户、组织、数据范围和状态仍由原业务 API 校验。高风险动作在原业务 API 具备服务端确认约束前不得登记。

## 安装与入口

安装 `@levin/admin-framework`，以 `configureAdminApplication` 启动管理端并完成登录。全局布局自动挂载悬浮“AI助手”入口；展开后可选择当前租户已配置的供应商并输入任务。路由切换保留当前 SPA 会话，退出登录或身份切换时清除聊天内容。模型调用先读取后端 AI 插件已保存的网页配置，再由基础业务模块的 AI SDK 模型客户端通过受控浏览器原生 fetch 直接请求供应商；后端不转发模型消息。未开启网页直连或配置不完整时显示无可用模型，不能回退本系统后端聊天接口。

## 技能开发

业务模块从包公共入口导入 `registerAdminAgentSkills` 与 `AgentSkill`，在模块 `setup` 中以模块 ID 登记技能。稳定技能 ID 必须以模块 ID 开头。每项技能声明名称、说明、输入 Schema、风险、单次记录上限和所需权限；处理器必须校验允许字段、类型、范围和分页参数。读写请求应复用该模块已有的 API service，使当前登录会话与既有请求拦截器继续生效。

```ts
import { registerAdminAgentSkills, type AgentSkill } from '@levin/admin-framework';

const skills: AgentSkill[] = [
  {
    id: 'example.module.record.list',
    description: '查询当前用户有权查看的记录',
    inputSchema: { required: [], properties: { limit: { type: 'integer', maximum: 20 } } },
    maxRecords: 20,
    permission: '记录查询权限',
    risk: 'read',
    execute: async (args) => ({ count: 0, data: [], source: '记录查询接口' }),
  },
];

registerAdminAgentSkills('example.module', skills);
```

这个示例只说明登记形状；真实技能必须调用授权业务接口并验证响应，不得把空结果处理器作为业务实现。注册拒绝重复技能 ID。集中 Schema 校验会在处理器之前拒绝额外字段、缺少必填项、类型、长度、数值范围和枚举不匹配，具体语义仍须处理器校验。

普通写入应声明 `writeIntent: ['修改客户', '更新客户']` 等经过业务审查的明确意图词，通过 `preview` 返回差异说明、`execute` 和只读 `recheck`；没有意图声明的确认技能不会由模型自动触发。确认时重新读取对象、检查当前身份、权限、范围和版本，单次尝试后禁止重放，调用原 API 后读回核验。状态变更不能通过直接写状态字段绕过原业务命令；不得在生成模型回复阶段产生副作用。

## 运行与错误语义

每轮最多 8 个步骤，技能 Schema 发现与实际调用共用预算。目录保留全部授权技能 ID，以有界摘要呈现；模型可输出 `{"type":"skill_schema","skill":"登记 ID"}` 读取完整参数说明，再输出原有 `skill_call`。最多 120 项技能、目录 16k 字符，历史最多 12 条且 24k 字符；累计最多 100 条结果、单次结果 12k 字符、累计结果 24k 字符。超限明确返回部分完成或错误，不静默把分页结果当作全库统计。

面板执行记录显示技能、状态、条数和来源，不显示原始参数与数据。任务运行时可点击“停止当前任务”，中止在途模型请求并阻止新步骤；已发出的业务请求仍可能完成，停止不等于撤销。确认修改且读回成功后可继续原任务；后续写入仍须重新预览。刷新或关闭网页不保证任务继续，也不重放已尝试写入。

模型未选择技能时，界面明确标示未调用系统能力；模型建议未登记技能、额外参数或超限查询时直接拒绝。技能调用失败返回可行动错误，不将其解释为业务已完成。仅在业务 API 调用后重新读取并核验成功，界面才报告“已执行”。若写入后的响应或核验不确定，界面锁定该次预览，只允许只读“复查”或结束跟踪，不能盲目重发。

## 安全与最小验证

管理员必须显式开启默认关闭的网页直连并配置独立网页凭证，后端密钥不会发给浏览器。网页凭证对当前租户登录用户可见，只能在内存使用，不得放入 localStorage、sessionStorage、聊天消息或日志；身份、租户、组织及域变化时使旧配置和会话失效。供应商侧须限制额度、模型和凭证使用，前端限制与调用上报不能替代可靠服务端配额或完整审计。浏览器的技能过滤只是体验层；服务端必须独立授权。扩展者至少验证普通用户与超级管理员技能目录、越权拒绝、参数注入、分页上限、路由切换与登出清理、写入预览及后置核验，并在真实页面确认聊天窗可用。诊断日志类技能只允许超级管理员登记和调用，且服务端仍需强制校验。

## 模型传输扩展

业务模块登记模型传输时，先通过受控配置 API 取得已保存的网页端点、独立网页凭证和别名映射。基础业务模块现使用 `ai@6.0.309` 的 `generateText` 与官方 `@ai-sdk/openai-compatible@2.0.85` 的 `createOpenAICompatible`，明确传入供应商模型对象，并注入受控独立原生 fetch 请求供应商 HTTPS API。此路径不使用默认 AI Gateway，不要求 Vercel 账号或托管服务；自动重试设为 0，遥测关闭。不得复用携带业务 Token/Cookie 的业务 HTTP 客户端向供应商发请求；不跟随重定向，限制超时与响应大小，脱敏上游错误。供应商 CORS 必须允许页面来源，页面 CSP 的 `connect-src` 须允许供应商；失败时明确报错，不通过后端代理或关闭浏览器保护绕过。Claude Code CLI 无法在纯网页运行，不得以普通 Claude 模型 API 冒充。

最小验证还需在浏览器 Network 检查供应商实际请求目的地、系统认证隔离、配置无持久缓存及作用域切换失效；模拟 CORS/CSP、认证与超时失败，确认没有请求本系统后端 `chat`/`stream`。

## AI SDK 能力与采用范围

[AI SDK](https://ai-sdk.dev/docs/introduction)按 [Apache-2.0](https://github.com/vercel/ai/blob/main/LICENSE)免费开源，模型供应商费用另计。它提供文本/流式生成、结构化输出、工具与 Agent 等能力；多模态和嵌入取决于供应商。当前接入仅统一文本模型客户端，现有 8 步循环、显式技能和写入确认继续由平台控制，未采用 `ToolLoopAgent`，也不表示已有流式 UI、图片生成或 RAG。接入兼容供应商参见[官方适配器文档](https://ai-sdk.dev/providers/openai-compatible-providers)。

### 网页模型未启用的排查

管理员在“服务插件设置管理”选择当前租户/域名的 AI 供应商设置，启用插件及供应商，开启“启用网页直连”，填写“网页专用 API Key”、有效 HTTPS 端点及启用的模型别名，并选择有效默认模型别名。网页密钥独立于后端 API Key，不自动复用。没有可用配置时，AI助手保留输入并显示配置提示，不请求模型；配置保存后收起并重新打开助手可刷新空目录。选择“系统默认”会使用当前授权目录首项；显式选择的模型失效时提示刷新，不静默切换供应商。
