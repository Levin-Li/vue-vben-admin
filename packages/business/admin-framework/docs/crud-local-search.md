# 标准 CRUD 本地选项搜索使用说明

## 入口与前置条件

标准 CRUD 查询、新增和编辑表单中的可搜索下拉框，使用已加载选项在浏览器内过滤时，自动启用本规则。页面继续按现有方式配置选项的 `label` 和 `value`，无需额外开关或字段配置。需要先加载相应的本地选项；本规则不会请求更多候选项。

## 搜索方式

- 显示文本采用忽略英文字母大小写的模糊包含匹配。例如“用户管理”可用“户管”查找，“User Management”可用“Manage”查找。
- 中文显示文本支持无声调完整拼音和各汉字拼音首字母的模糊包含匹配。例如“用户管理”可用 `yonghu`、`huguan`、`yhgl` 或 `hg` 查找。
- 英文显示文本支持按单词首字母组成的字母串进行模糊包含匹配。例如“User Management”可用 `um` 查找。中英混排名称可组合中文拼音或首字母与英文单词；拉丁字母匹配忽略大小写。
- 保留原有按选项 `value` 文本包含匹配的兜底行为。匹配只影响选项显示，不改变选中值、提交值或字段权限。

## 公共匹配方法

自定义页面复用相同的本地文本搜索规则时，通过包公开入口调用 `matchesPinyinFuzzySearch(keyword, originalText): boolean`。第一个参数是用户输入的关键字，第二个参数是实际展示的原文本；返回 `true` 表示匹配。空关键字返回 `true`。选项值兜底由调用方另行判断，不应把 `value` 拼接进原文本。

```ts
import { matchesPinyinFuzzySearch } from '@levin/admin-framework';

const matched = matchesPinyinFuzzySearch('hg', '用户管理'); // true
```

需要过滤选项时，将每项的显示文本传给此方法；标准 CRUD 已自动接入。传入的数据必须是页面已经加载、允许当前用户看到的文本；此方法不负责请求数据或判断权限。

## 边界与验证

配置 `remoteSearch` 且由 `loadOptions` 提供候选项的字段仍按原有接口远程搜索；页面端不会对其已加载选项额外套用拼音过滤。服务端查询、接口参数和数据库搜索不受本规则影响。其它自定义页面的本地搜索需要按页面开发规则另行接入，不能仅因使用本包就视为已经覆盖。

最小验证：在一个使用本地选项的标准 CRUD 下拉框中，用中文片段、完整拼音片段、拼音首字母片段和英文单词首字母分别查找对应选项；再确认选中与提交值不变，并在远程搜索字段输入关键字时确认仍调用原有接口。
