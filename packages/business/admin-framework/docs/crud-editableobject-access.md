# EditableObject 标准 CRUD 使用说明

## 适用范围

实体实现 `EditableObject`，且对应 CRUD 字段元数据包含 `editable` 时，公共 `CrudPage` 启用本规则。仅字段名相同但实体不具备该能力的页面，应先修正后端元数据，不要在页面伪造字段。未声明 `editable` 的页面保持原有行为。

## 页面行为

- 超级管理员在查询、新增、编辑和列表中看到“是否可编辑”，并可操作 `editable=false` 的记录。
- 非超级管理员在上述四处均不看到该字段；`editable` 不严格等于 `true` 的记录不提供内置编辑、删除和快捷布尔更新。
- 系统设置页的“编辑值”遵循同一超管例外；普通用户仍受记录 `editable` 标志控制。
- 列表详情仍可按原有权限查看。页面展示设置不会放宽上述字段和操作权限，服务端 API 权限仍是最终边界。

## 接入与最小验证

在页面配置中保留后端下发的 `editable` 字段元数据，使用标准 `CrudPage`，无需额外开关。分别以超级管理员和普通用户打开同一支持 `EditableObject` 的页面：检查四处字段显隐、`editable=false` 行操作，以及对应更新请求的成功或权限错误。若接口拒绝，按服务端权限和数据范围诊断；不要仅根据按钮显隐推断服务端已授权。
