# 公共 CRUD 表头排序使用指南

## 入口与默认行为

公共 CRUD 列表中，名称、类型、类别、枚举、数据字典和日期时间字段在具有后端排序字段时默认显示表头排序入口。点击表头后，当前列表重新请求数据，并在分页、查询和刷新时保持该排序。多列表页面分别保存各自当前排序状态。

金额、数量、编号等其他后端标量字段默认不显示排序入口。具有页面展示设置管理权限的管理员可进入该 CRUD 页的“页面展示设置”→“列表”→选择列，切换“是否可排序”；保存后该列按设置显示或隐藏排序入口。普通用户使用管理员保存的设置，不需要自行配置。

## 配置边界

- 排序字段必须由后端列表接口支持。普通字段默认以字段 `key` 请求，页面可使用 `sortFieldPrefix` 指定主表别名前缀；关联、计算或特殊展示列须由开发者用 `sortField` 指定精确后端排序字段。
- 字段配置 `sortable: false` 会禁止 UI 开启排序。操作列、虚拟列、无后端字段、复杂值及前端计算展示列，没有明确 `sortField` 时也不能通过 UI 强行开启。
- 枚举与数据字典的默认识别依赖选项来源元数据；普通远程关联选项不自动按枚举处理。页面开发者应确认列表接口接受选定的排序字段。
- 表头排序请求使用 `orderBy` 和 `orderDir`，方向为 `Asc` 或 `Desc`。接口不支持字段时会由列表接口返回错误；管理员应关闭该列排序，开发者应修正字段映射或接口支持。

## 最小验证

在列表中点击一个默认可排序列，确认请求包含对应 `orderBy` 与 `orderDir`，并核对数据顺序。再在页面展示设置开启一个默认关闭的后端标量列，保存后点击其表头，确认使用该列后端字段排序。对 JSON、图片或前端计算列，确认“是否可排序”不可开启。
