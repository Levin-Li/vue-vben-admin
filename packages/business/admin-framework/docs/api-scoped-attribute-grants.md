# 接口级数据授权接入指南

字段权限决定接口字段能否展示、查询或编辑；字段值数据范围决定当前用户通过该接口可操作哪些记录。两者分别授权，也可同时生效。字段值范围由服务端强制校验：查询和删除限定原记录，新增校验新值，修改同时校验原记录与目标值；页面隐藏不能替代后端校验。

## 入口

在角色管理的“资源权限分配”中，找到真实 API 对应的操作行。当前操作有服务端登记的信息组或受控枚举／字典字段时，操作旁显示对应勾选入口；没有候选时沿用普通操作授权。页面不新增独立权限矩阵，勾选结果仍保存到角色的 `permissionList`。

权限树分类标签显示该分类总条目数；有已选权限时，标签同时显示绿色已选数量角标。“只显示选中项”开关位于“已选 / 未选”统计之后，默认关闭，开启后只保留选中权限及其父级路径，可继续配合分类切换和搜索使用。

信息权限标签的悬浮提示会列出已选信息组及其成员字段，并单独列出已选枚举／字典值。资源权限弹窗宽度为视口的 85%；计算宽度不足 1080px 时使用 1080px。

## 操作与保存

1. 先确定目标操作，再勾选该操作可使用的信息组和字段允许值。信息组来自该操作的请求／响应模型；枚举、字典候选必须由服务端附带 `sourceKind` 与 `sourceKey`，前端不得根据显示标题或接口路径自行构造来源。
2. 枚举值提交常量名，字典值提交服务端返回的真实 `code`，不提交中文标签。一个操作的多组、多字段、多值合成一条以 `@` 开头的权限字符串；无附加限制时保存普通四段操作权限。
3. 打开旧角色时，未映射的旧权限原样保留，不在页面加载或保存时自动变成新格式。撤销操作权限时应一并核对其附加配置；前端显示不能代替后端转授及运行时校验。

## 示例与边界

```text
@com.levin.oak.base:系统数据-用户::查询列表:@销售信息|enum#com.levin.oak.base.entities.User$Sex#sex@Man@Women|dict#com.levin.oak.base.entities.User.type#type@<字典项code>
```

该示例仅说明序列化语法，不表示 `User.sex` 或 `User.type` 已在生产启用数据范围。`::*` 只覆盖第三段资源标识为空且与操作模式匹配的接口。普通短通配、角色码、既有六段枚举值权限不是新 `@` 表达式，不能按第四个冒号统一截断。

## 最小验证

使用隔离角色分别给查询和修改接口配置不同的信息组或字段值，保存、关闭并重新打开弹窗核对回显；确认没有附加授权的操作仍是四段字符串。再以该角色调用真实接口，核对无权输入拒绝、无权输出过滤，以及数据库返回记录和 COUNT 均符合受控范围。
