# 全局组织与用户选择器

底层 `UserOrgSelector` 保持通用：只加载候选、保存选中记录并发出事件。调用方通过 hook 或包装层决定候选来源、默认值、显隐、是否允许清空和选中校验。

全局包装层规则：所有选择器默认空选。普通用户实际可操作候选不大于一时隐藏且不注入上下文；候选大于一时展示，选中后不可主动清空。管理员和超级管理员只要服务端启用组织与用户选择器即展示，并可清空。领域选择器候选不大于一时隐藏，当前固定为单选且允许清空，远程 `multiple` 配置不会生效。组织与用户选择器在 `multiple=true` 时支持服务端 `maxSelectCount`：正整数限制最多选择数，缺失或非正值不额外限制。全局上下文只通过请求头传递，不再覆盖查询面板或业务请求参数。
