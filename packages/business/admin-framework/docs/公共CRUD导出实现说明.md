# 公共 CRUD 导出分页实现说明

## 模块落点

公共页面组件 `src/framework-commons/shared/dynamic-crud-page.vue` 的 `fetchExportRecords()` 完成导出分页。它调用当前列表的 `apiService.list`；页面设置专用列表路径时，改用 `src/framework-commons/api.ts` 的 `fetchCrudList()`，后者请求 `requireTotals` 并统一列表响应的 `items`、`totals`、`pageIndex` 和 `pageSize`。文件由前端 Excel XML 构造器生成并下载，不调用独立的后端导出端点。

## 运行行为

单次导出冻结查询、排序与当前 `ListTable`，用 `pageIndex=1,2,…` 请求 `pageSize=2000`。每页完成字段组输出裁剪与权限快照检查；有效总数已取足或遇到空页才结束。后端实际返回较短页时仍继续，避免裁剪页大小造成首批漏页；相邻页稳定 ID 相同则抛出分页未推进错误，不下载文件。导出确认前检查总数是否超过 50,000，读取时也检查累计记录数，覆盖总数缺失或变化。

字段弹窗按当前列显示和顺序组织，允许选择、重排及标题别名；单元格优先使用列表展示值。成功下载后刷新当前列表，刷新失败只提示列表刷新问题，不否定已下载文件。导入由同一页面的 `handleImportConfirm()` 按 `batchCreate` 权限分批提交，未因本次分页修复改变。

## 最小验证与限制

为列表适配器提供三页数据：请求 2000、服务端实际每页 100、总数 250，文件应有 250 条数据。再分别验证无有效总数读到空页、重复页报错、超过 50,000 条拒绝、分页时查询和排序不随界面草稿变化。真实页面应核对导出行数与列表总数；其它子系统若使用专用导出代码，需检查它是否使用此公共入口。
