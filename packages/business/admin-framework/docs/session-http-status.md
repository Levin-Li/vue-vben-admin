# 会话复核与 HTTP 状态

管理端使用公共请求客户端时，业务接口返回 401 会静默请求当前用户信息，确认会话是否已经失效。本人信息接口返回明确的 401 才触发重新认证；正常返回、403、服务故障或网络失败均保留当前会话，并向调用方返回原业务请求的错误。旧服务把 Sa-Token 上下文故障错误地返回 401 时，也会保留会话。

同一令牌的并发复核会合并；复核期间若用户切换账号，不会清除新会话。复核请求本身不再递归复核。若应用显式启用了令牌刷新，确认失效后仍遵循既有刷新和重试配置；重试时重新准备签名和加密材料。

后端应将未登录或登录失效返回 401，将明确的权限、角色或签名认证拒绝返回 403；内部上下文故障返回 500，存储不可用返回 503。403 不触发重新登录，调用方应展示权限或业务错误。请求和响应的签名、加密验证仍然生效。

验证时可分别模拟业务接口 401 且本人信息成功、本人信息 401、本人信息 503，以及业务接口 403：只有本人信息明确为 401 时才应进入重新认证。该机制不能修复不存在的业务接口或替代服务端权限检查。
