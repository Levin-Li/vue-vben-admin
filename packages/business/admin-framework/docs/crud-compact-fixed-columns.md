# 紧凑表格固定列使用指南

公共 CRUD 列表的实际表格宽度小于 640px 时进入紧凑模式。此时保存的左右固定列仍保留在列配置中，但默认暂时取消固定定位，所有列仍可通过横向滚动查看。

1. 页面配置可为列表字段设置左固定或右固定；有操作列时，该列属于右固定组。保存的字段位置与用户浏览器中的列显示、顺序设置不因进入紧凑模式而改变。
2. 紧凑模式且存在固定组时，固定组的表头显示图钉。左侧图钉位于第一个左固定字段表头；右侧图钉优先位于“操作”表头，没有操作列时位于最后一个右固定字段表头。鼠标悬停可看到“展开/收起左固定列”或“展开/收起右固定列”，键盘和读屏可使用同名按钮。
3. 点击图钉只在本次紧凑视图临时固定对应的一侧；再次点击收起。一次仅临时固定一侧。表格恢复宽布局时清除临时状态，并按原保存配置固定列。图钉不会触发表头排序。

图钉不改变权限、接口请求、数据范围或记录内容。无法看到图钉时，先确认表格实际宽度低于 640px、该侧确有可见固定列，以及列设置没有隐藏相关字段；无需为了显示图钉修改数据。最小验证是在紧凑宽度下展开和收起图钉，观察对应列的固定定位变化，再加宽列表确认原配置恢复。
