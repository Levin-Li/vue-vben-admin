# 接口级数据授权前端设计

角色资源权限分配沿用已有模块、资源和操作树。每个操作行展示该操作可分配的信息组、受控枚举字段及受控字典字段；没有候选的操作不增加入口。服务端仍是唯一授权事实源，前端不扫描 Java 注解、不根据页面标题或路由拼接权限候选。

同一操作的多个组、字段及允许值序列化为一条 `@` 复合权限；普通四段操作、角色码、旧 `:@value:` 和其它旧权限保持原值。服务器明确下发 `wildcardOperation` 时才显示“同类全部操作”配置；前端必须按组来源标识和字段来源键消歧，不能以同名文本合并不同实体的组。

页面只负责候选展示、勾选、回显及格式校验。操作许可、来源身份、字典 code、机密等级、数据范围和角色转授最终由后端重新检查；保存失败须保留当前选择供修正。
