# 资源权限的菜单祖先选择策略

`ResourcePermissionDialog` 和 `ResourcePermissionTreeEditor` 可选接收 `autoIncludeMenuAncestors` 回调。回调接收菜单路径并返回布尔值；多选模式下，勾选匹配的具体菜单时，编辑器同时选中后端权限树中可见的祖先菜单展示权限。未提供回调时，菜单仍按原有方式独立选择。后端权限树中找不到对应菜单时，不从旧菜单树或显示名称推测祖先权限，并提示管理员核对上级权限。

该策略要求展示节点与后端节点的标识、路径和权限表达式一致，只补充格式有效的系统菜单“展示”权限，不选择兄弟菜单、操作权限或数据权限；取消叶菜单不会自动取消已有父菜单权限。单选模式不补充祖先。权限树缺少祖先时不会猜测或拼接权限，服务端仍负责核对完整菜单链、额外权限及数据范围。

接入方应只匹配自己能够确认的具体菜单路径，并在权限树可用时启用策略。例如报表模块只匹配服务端生成的具体报表菜单，不对所有菜单启用。最小验证：勾选目标菜单后确认父菜单和目标菜单被选中、兄弟菜单未选中；不匹配路径仍保持原有独立选择；保存后用实际账号验证服务端授权。
