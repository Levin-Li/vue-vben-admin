# 公共 CRUD 列表临时调整列宽

## 入口与操作

使用公共 `CrudPage` 的列表在桌面表格表头显示列宽拖动把手。把鼠标移到普通数据列右边界并左右拖动：向右使该列变宽，右侧可调整的数据列按各自可缩空间比例缩窄；向左使该列变窄，右侧列扩展。表格整体宽度保持不变。某列达到最小或最大宽度时，拖动在可用边界停止。

无需额外配置或权限。列表右侧的“操作”列、隐藏列和最后一个没有右侧可调整数据列的边界不参与拖动。原有“列设置”仍负责显示和顺序；管理员的“页面展示设置”仍决定默认列宽与边界。拖动结果只在当前页面实例生效，列表刷新、排序和翻页时保留；浏览器刷新或切换另一张 `ListTable` 后恢复默认分配。不写入本地存储或服务端，也不影响其它用户。

## 结果与排查

拖动时没有保存按钮，也不会调用业务 API。若把手不出现，先确认该列右侧还有可见数据列；若不能继续拖动，检查目标列最大宽度和右侧列最小宽度。窄屏下仍可使用表格横向滚动及已有的固定列收展入口。

最小验证：在列表拖动一列表头边界，确认该列及右侧列宽相反变化；点击列表刷新确认宽度仍在；刷新浏览器确认恢复默认宽度。若页面支持表头排序，再点击排序确认列宽不被重置。
