# 邮件中转路由使用指南

## 前置条件

管理员须先在“服务插件配置”中启用 Forward Email，并为平台或目标租户填写 `apiToken`。租户配置优先于平台公共配置。Token 仅用于服务端访问 Forward Email，不应写入路由备注、投递目标或页面 JSON。

## 配置路由

在“应用&接入 / 邮件中转路由”新建记录，填写邮件域名、别名、提供商 `Forward Email`。在“投递目标”子列表点击“新增目标”，通过弹窗填写邮箱、完整邮件 Webhook 或通知 Webhook 的类型与地址；已有目标可逐行编辑或确认删除。Webhook 必须是公网 HTTPS 地址，保存时至少保留一个合法目标。

先执行“预检”，再执行“预检 DNS”并按返回说明在 DNS 托管商手动配置记录。DNS 记录不会由本系统写入。确认后点击“同步”，系统会创建或更新其受管的 Forward Email alias。

## 变更与删除

修改目标或启用状态后，路由会回到待同步状态，需再次同步。已同步路由的域名、别名和提供商不可直接修改；请先使用“删除提供商资源”，再调整身份字段并同步。该删除只删除受管的 Forward Email alias，不删除本地路由记录或 DNS 记录。

## 安全边界

Webhook 内容和重试由 Forward Email 原生处理；本系统不保存或转发邮件正文、附件。提供商失败时页面会显示脱敏错误摘要和 `Failed` 状态，修正配置后可重新同步。
