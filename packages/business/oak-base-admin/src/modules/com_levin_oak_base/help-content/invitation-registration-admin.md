# 邀请注册链接使用指南

> 外部邀请成功后，客户或伙伴主档的 `orgId` 是此次新建的外部子组织节点，不是签发人的内部组织；主档不设置个人所有者。详细规则见外部组织主档管理页面使用指南（资料未收录在线帮助）。

## 入口与前提

有相应签发权限的后台用户进入“用户&权限 → 邀请注册链接”。租户登录配置中的“邀请注册”须开启，受邀人才能兑换链接；它与普通自注册开关独立。普通自注册只接受手机号或邮箱，创建的账号不加入组织。

## 创建链接

1. 选择内部用户、会员用户、客户、供应伙伴或渠道伙伴。客户和伙伴固定为每位注册者新建外部子组织；内部及会员可选加入推荐人组织或每人新建子组织。
2. 选择普通用户或子组织管理员。子组织管理员只能用于新建子组织，权限只覆盖所建节点。客户请选择直接客户或渠道客户；供应和渠道伙伴请选择具体业务类型。
3. 选择允许的注册方式、未来的过期时间，以及单次、限定人数或不限人数。签发后这些策略不可修改，也不能删除链接。
4. 创建完成后复制链接。日后可在列表中通过“加载更多”翻看较早签发的链接，再次点击“复制链接”；系统会重新授权并从服务端取得完整地址。列表本身只显示摘要。

签发人、租户、父组织和默认角色由服务端确定，页面不能指定任意 ID 或角色。管理人员可输入原因作废链接；作废保留审计事实。

## 受邀人注册

受邀人打开链接后，页面先向服务端核验链接，再展示邀请目标和允许的注册方式。手机号须使用短信验证码，邮箱须使用邮件验证码。外部组织注册还需填写新组织名称、法律主体名称和统一社会信用代码；同租户已存在该身份标识时，注册会被拒绝并提示联系管理员。后台用户注册成功后可前往后台登录；本期会员只完成注册，不自动登录，后续由所属客户端提供会员登录入口，本管理后台 `/auth/login` 不是会员登录入口。会员通过第三方邀请注册时，还需验证手机号或邮箱并设置登录密码。

链接签名错误、到期、作废、名额已满或租户关闭邀请注册时，页面不显示可提交表单，也不会降级为普通自注册。

## 验证方法

在测试租户分别创建单次和限额链接，用新手机号或邮箱完成一次注册，确认账号与组织归属；再次兑换单次链接应失败。作废后应拒绝预览和兑换。仅普通自注册关闭而邀请注册开启时，有效邀请仍应可用。生产环境还需验证短信／邮件供应商配置和第三方认证回调。
