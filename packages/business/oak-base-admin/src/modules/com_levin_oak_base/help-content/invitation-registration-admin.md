# 邀请链接使用指南

> 外部邀请成功后，客户或伙伴主档的 `orgId` 是此次新建的外部子组织节点，不是签发人的内部组织；主档不设置个人所有者。详细规则见外部组织主档管理页面使用指南（资料未收录在线帮助）。

## 入口与前提

有相应目标签发权限的后台用户进入“用户&权限 → 邀请链接”。创建入口按标准 CRUD 的 API 权限显示，页面不常驻展示签发资格信息。实际签发仍须属于有效租户和有效内部组织；平台超管身份不能代替租户、组织，服务端会在提交时校验并返回业务原因。租户登录配置中的“邀请注册”须开启，受邀人才能兑换链接；它与普通自注册开关独立。普通自注册只接受手机号或邮箱，创建的账号不加入组织。

## 创建链接

1. 点击内部用户、会员用户、客户、供应伙伴或渠道伙伴对应的标准签发动作。这些入口采用各 API 的 `@CRUD.Op` 声明并复用公共 CRUD 表单，不再通过工具栏目标下拉切换泛化新增接口；打开后本次目标和提交接口固定。客户和伙伴固定为每位注册者新建外部子组织；内部及会员可选加入推荐人组织或每人新建子组织。
2. 按目标选择普通用户或子组织管理员，会员仅允许普通身份。子组织管理员只能用于新建子组织，权限只覆盖所建节点，且签发人需要相应附加权限。客户请选择直接客户或渠道客户；供应和渠道伙伴请选择具体业务类型。
3. 选择允许的注册方式、未来且距离当前时间小于 366 天的到期时间，以及单次、限定人数或不限人数。限定人数须为 1 到 10000 的整数，单次/不限人数不填写人数上限。签发后这些策略不可修改，也不能删除链接。
4. 创建完成后在结果弹窗复制链接；关闭弹窗后，完整链接不留在列表区域。日后可通过列表分页翻看较早签发的链接，再次点击“复制链接”；系统会重新授权并从服务端取得完整地址。列表本身只显示摘要。

查询栏可按邀请目标、用户类型、注册方式、使用次数和到期时间范围筛选。到期时间用一个起止时间范围组件，分别提交 `expiresAfter` 和 `expiresBefore`；列表行可查看授权范围内的详情。列表加载失败时仍可使用“刷新”重试；错误以短暂提示出现，不占据工具栏和表格之间的空间。

签发人、租户、父组织和默认角色由服务端确定，页面不能指定任意 ID 或角色。管理人员可输入原因作废链接；作废保留审计事实。

资格、日期、人数或组织模式不满足时，保存显示对应的安全业务原因；请求层已经提示的错误不会再追加泛化“保存失败”，草稿保留便于修正。后端仍重新检查真实账号、组织及授权，页面打开不代表任意账号都可签发。

## 受邀人注册

受邀人打开链接后，页面先向服务端核验链接，再展示邀请目标和允许的注册方式。手机号须使用短信验证码，邮箱须使用邮件验证码。外部组织注册还需填写新组织名称、法律主体名称和统一社会信用代码；同租户已存在该身份标识时，注册会被拒绝并提示联系管理员。后台用户注册成功后可前往后台登录；本期会员只完成注册，不自动登录，后续由所属客户端提供会员登录入口，本管理后台 `/auth/login` 不是会员登录入口。会员通过第三方邀请注册时，还需验证手机号或邮箱并设置登录密码。

链接签名错误、到期、作废、名额已满或租户关闭邀请注册时，页面不显示可提交表单，也不会降级为普通自注册。

## 验证方法

在测试租户分别创建单次和限额链接，用新手机号或邮箱完成一次注册，确认账号与组织归属；再次兑换单次链接应失败。作废后应拒绝预览和兑换。仅普通自注册关闭而邀请注册开启时，有效邀请仍应可用。生产环境还需验证短信／邮件供应商配置和第三方认证回调。

对创建入口，应使用具备有效租户和组织的测试账号，从对应目标动作打开表单，填写日期及人数后实际点击保存；确认成功后出现链接结果，拒绝时保留草稿且只提示一次。另检查无组织账号、过去/超过边界的日期、人数越界和管理员模式冲突均被拒绝。仅打开列表或表单不等于保存链路通过。
