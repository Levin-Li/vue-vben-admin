# 用户个性化设置使用指南

入口位于“用户与权限”分组的“用户个性化设置”，新地址为 `/clob/V1/UserPersonalSetting`。旧菜单地址 `/clob/V1/UserSetting` 可继续打开同一页面。

登录后可查询、创建、查看、修改和删除自己的设置；列表中不能选择其他用户或租户。服务端使用当前登录身份限定所有者，即使请求包含其他用户的 ID 或所有者参数也不能访问对方记录。批量操作不开放。

新增时填写分类名称、编码和值类型等必填项；编辑时需带当前乐观锁值。成功后列表展示本人记录；无权或不存在的记录会返回错误。验证时用两个不同账号分别创建设置，再尝试以另一账号的记录 ID 查看或修改，预期被拒绝。
