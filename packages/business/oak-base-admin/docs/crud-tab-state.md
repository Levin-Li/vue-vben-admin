# 标准 CRUD 标签状态使用说明

本包注册的标准 CRUD 页面在宿主开启标签栏缓存时，会保留同一标签内的分页、查询、排序及未关闭的页面局部状态。切到其它标签再返回，不会仅因切换而把列表重置到第一页。

关闭标签后重开、手动刷新、切换租户等全局请求上下文，或关闭标签缓存后，页面仍会重新加载。标签缓存不改变接口权限和服务端数据；需要查看最新结果时使用页面刷新。

最小验证：打开“系统设置”等标准 CRUD 页面，切到第 2 页，切换到“服务插件设置”再返回，确认页码仍为 2；手动刷新后确认页面重新请求数据。后台菜单映射和其它项目的接入方式见 `@levin/admin-framework` 包内 `docs/crud-tab-cache.md`。
