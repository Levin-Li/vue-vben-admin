# 报表中心前端实现说明

管理页面负责报表列表、草稿设计、保存和发布；运行页面根据菜单固定参数加载已发布报表，通过共享条件驱动各组件查询。设计器只保存受信目录中的来源、字段、关联和参数配置，服务端对每次查询和导出重新授权。

页面使用请求序号和身份上下文丢弃过期结果，缓存标签失活时清除旧数据。创建或复制请求的结果不确定时，当前页面提示核对并阻止直接重复提交；这些状态仅在当前页面有效，不提供跨会话或服务端幂等。

图表复用共享控件，金额及数量显示保留字符串精度；导出重新请求授权数据。示例预览使用虚构数据，已保存预览才访问服务端。接口默认关闭，真实部署及生产安全验收尚未完成。操作步骤见[使用指南](report-center.md)，扩展要求见[开发指南](report-center-development.md)。
