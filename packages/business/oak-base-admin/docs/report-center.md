# 报表设计页面使用指南

在管理后台的“报表中心”分组进入“报表设计”。页面按当前用户的报表管理权限显示列表和操作；后端会再次校验租户、组织、资源动作及菜单权限。创建租户报表时选择有权访问的组织；平台全局视角创建的报表不指定组织。

当前并发授权修复期间，报表写入暂不可用：页面会隐藏新建、编辑和发布等入口，已保存草稿仍可在预览能力开放且具有相应权限时预览。能力状态无法取得时，页面不会开放写入；后端仍会独立拒绝未完成安全保障的写请求。

具体报表运行页只有在当前账号具备复制权限且复制服务明确可用时显示“复制为租户报表”；能力请求失败或切换身份时，入口会隐藏。复制请求仍由后端独立检查来源和数据范围。

能力状态查询较慢时，已授权报表和管理列表仍可先显示；写入与复制入口会等状态明确后再决定是否开放。

在设计器点击“预览”打开独立窗口；标题、字段、图表类型、位置和背景变化会实时反映在窗口中。窗口关闭后可再次点击打开，若浏览器拦截弹窗请允许弹出窗口。预览使用虚构示例值，不查询或保存业务数据；要查看实际数据，请先保存草稿并使用“预览草稿”。

报表以整份报表的菜单为授权单位，数据集跟随所属报表，不单独分配权限。查看和导出不应用字段权限或字段脱敏；获得菜单权限的用户可看到报表配置中的全部输出字段，设计者和授权管理员须据此审查敏感字段。租户、组织及其他已支持的数据范围仍由服务端约束。

图表使用浏览器浮点数定位；极小非零数值或饼图中无法表示的非零比例会提示查看数据表，数据表保留服务端返回的原值。饼图数值之和超出浮点范围时会等比例缩放以计算占比，悬停仍显示原值。

有报表详情权限的管理者可在列表点击“发布日志”，查看该报表的发布时间、操作人、动作和备注。日志读取受当前租户、组织和领域范围约束；无权限或范围不符时无法查看。尚未发布时日志为空。

普通导航下发时会重新检查报表的当前菜单授权、绑定和发布状态；报表入口关闭或检查不可用时隐藏报表菜单，其他菜单不受影响。为限制导航加载成本，单次候选报表菜单超过 256 个时会隐藏本次报表入口并记录告警，需由管理员调整后重新加载导航。打开报表时若读取失败，或组件查询失败且重新检查后报表不可用，当前会话也会隐藏对应报表菜单。网络故障也可能触发该处理，服务恢复后可重新加载导航；服务端仍对每次报表访问单独检查权限。

新建或编辑时，先添加数据集，从受信目录选择主数据源、关联、展示字段及筛选项；再添加页面共享条件，把组件的数据集筛选项绑定到对应条件。选择“所有报表联动”时，每个组件都必须绑定该条件。组件可选择表格、指标卡和基础图表，12 列网格可拖到空白位置或拖到另一组件交换位置；尺寸不兼容、越界或重叠时会提示并保持原布局。自由画布支持拖动位置并手动调整尺寸，窄屏网格按从上到下、从左到右排列。可配置背景颜色，或选择不超过 256 KiB、宽高均不超过 2048 像素的 PNG 或 JPEG 背景图片。图片随草稿及发布版本保存，读取发布页面时需要报表权限。创建、保存和发布均要求操作者有报表管理权限，并重新检查配置中的来源、字段和关联是否在受信目录中。

手动输入网格组件位置或尺寸时，若与其他组件重叠，保存前会提示调整；后端在创建、保存、发布和复制时也会检查。自由画布允许组件叠放。历史已发布的重叠网格仍可读取，编辑后需调整才能再次保存或发布。

切换到网格时，组件按转换后的位置依次避让，必要时向下移动；无法在坐标范围内安全转换时会提示并保留原布局，需先调整组件位置或尺寸。自由画布拖动会保留鼠标抓取点，滚动后也可继续调整位置。

网格组件可选择“一行一个”“一行两个”或“一行三个”，系统只移动当前组件以避让其他组件；也可以直接拖动预览卡片。页面背景可设置纯色或两个颜色的渐变，方向可选从左到右、从上到下或斜向；每个图表也可独立选择预设配色、纯色或两色渐变。背景图片与渐变同时存在时，图片位于渐变之上。

移除已被组件绑定的共享条件时，页面会提示绑定将被解除；取消会保留条件与绑定，确认后需为相关筛选项重新绑定条件。未被引用的条件可以直接移除。

可以为数据集填写可选的业务名称；组件选择器和布局预览会显示序号、业务名称和来源，未填写时显示序号与来源。切换已绑定共享条件的组件时，页面会提示原绑定将清除；取消保留原配置，确认后请重新绑定。

需要制作相似分析时，可复制数据集及其多表关联、字段和筛选；数据集副本可以独立修改。也可复制报表组件，副本保留原数据集及共享条件绑定，但图表外观可单独调整；网格会自动避开已有组件。

展示字段可选择不排序、升序或降序，例如时间趋势按日期升序、排行按汇总金额降序。配置多个排序时，优先级按展示字段从上到下的顺序执行。排序在数据库取前 100 条数据之前应用。

添加展示字段时，设计器优先选中尚未使用的可用字段；所有字段都已使用时仍可重复添加，以便对同一字段配置不同的聚合方式。

平均值使用精确求和与非空数量计算；能够整除时保留完整精度，循环小数按 DECIMAL128 精度舍入。全为空的组显示空值；平均值排序由数据库执行。

数据集可填写“显示前”数量，范围为 1 至 100；例如将金额字段设为降序、数量设为 10，可制作前十排行。填写数量时必须至少配置一个排序字段。未填写时最多展示 100 条；实际结果超过配置数量时页面会提示结果受到限制。

电子发票申请数据源可在设计时添加状态或方向筛选，选择固定值或绑定“枚举”类型的页面共享条件；共享条件可在运行页面切换，并联动所有绑定的组件。同一共享条件绑定的字段必须具有一致的选项。不设置筛选时金额包含所有状态及红字申请，系统不会自动转换红字金额符号；未明确业务口径的汇总不能直接作为已开票收入或销售额。报表是否可见由报表菜单权限决定，查询仍受数据范围限制。

普通汇总下，一对多关联在左侧主键经服务端验证、且仅有一条放大关系时，可以按主表字段分组统计明细字段，例如按组织统计用户数量或汇总发票申请金额。主表字段聚合和多条放大关系需改用“按事实去重汇总”，以免重复计算。内连接不显示没有匹配明细的主表；左连接保留主表，明细计数为零，求和结果为空。

多表关联的数据范围由服务端自动应用到每个来源，无需在设计器为各表重复配置权限。左连接右侧记录超出可访问范围时，与没有匹配记录一样显示为空，不参与明细统计；如果再对右侧字段设置筛选，空匹配的主表行也可能被排除。

多表数据集先选主数据源，再依次选择已登记关系；每条关联显示来源、关联字段和基数，最多可包含八个来源。关联可选择内连接或左连接；左连接保留左侧有权访问的记录，右侧无匹配或不可见时显示空值。对右表设置筛选或后续使用内连接可能排除这些空值。移除关联时仅移除依赖它的后续关联及失去来源的配置，其他分支保留。字段和筛选项按来源名称区分；展示字段可填写业务显示名称，设计预览、运行页面和导出均使用该名称，留空时使用默认名称。切换字段会清除原显示名称；上下箭头可调整展示顺序，同时保留统计和排序设置。

数据集默认显示全部配置，也可使用“关联来源”“字段与统计”“筛选条件”逐步编辑；步骤只改变当前数据集的可见区域，不改变已填写的配置。每个数据集的步骤互不影响，示例预览仍可展开；选择“全部配置”可恢复完整视图。

多对多或多个明细来源同时汇总时，选择“按事实去重汇总”。每个指标在每个分组内按该指标来源的记录主键计算一次，即使不同记录的金额相同也分别计算；一条记录属于多个分组时会分别计入，各分组合计不一定可加。指标来源必须具有可识别的单字段主键；连接明细超过 50000 行或去重事实项超过 500000 条时会拒绝并提示缩小范围，不返回截断汇总。数字排序按数值比较，文本按字符顺序比较，空值排在最后。

展示字段可按来源或字段名称搜索并批量添加；已有字段及其统计和排序设置会保留。每个数据集最多 64 个展示字段，若所选字段超过上限，本次添加不会生效。

内置“组织”和“上级组织”可按上下级关系关联，也可从上级组织关联下级组织并统计明细。两侧分别应用当前用户的数据范围；左连接时无匹配或不可见关联方以空值表示。

发票状态和方向也可作为展示字段或分组维度，例如按状态统计申请金额；结果显示“已开具”等业务名称。枚举字段支持直接展示和计数，排序按底层枚举值进行，而不是按中文名称排序。

编辑关闭时如有未保存修改，页面会提示确认。保存失败时保留输入；版本冲突需要重新读取后再编辑。页面只提交报表设计、预期版本和明确的业务字段，不提交当前用户、租户或授权组织列表。

图表按数据集字段顺序解释结果：第一列为分类，其后每一列为一个数值系列；饼图必须恰好有一列数值，且不能出现负数。空值或非数值不会被当作零，运行组件会提示并保留数据表。运行页只读取具体菜单的固定报表标识，切换主体或权限时会清除旧数据。每个面板可选默认、蓝紫、柔粉或暖金配色，也可选择是否直接显示图表数据表。

当前报表或组件加载失败时页面会显示错误；切换条件或身份、关闭管理对话框后，旧请求失败不会再弹出过期提示。

报表结果不会因字段脱敏规则而隐藏或遮盖；不应向无权看到完整报表字段的用户授予该报表菜单。

环形图在图形周围显示分类与占比；空间不足时会隐藏重叠标签，完整数值可通过悬停或数据表查看。

金额和数量在指标、表格及图表中按四位分组，悬停显示亿、万等数量级并保留低位前导零，例如 `1,2000,0123元` 显示为 `1亿2000万0123元`；原始查询值不会除以一万。计数自动按数量展示；常见金额、数量字段按目录语义保守识别，费率、比例和编号不自动当作金额。无法识别的字段可在展示字段中选择“金额”或“数量”，也可显式选择“普通数值”；金额默认单位为元，其他币种须自行指定。表格和悬停提示保留服务端返回的精确十进制文本，图形位置受浏览器浮点精度限制。

需要按时间筛选时，可为内置用户或组织数据集选择“创建时间”，分别添加“大于或等于”和“小于或等于”条件，再绑定到页面的两个“日期时间”共享条件。结束时间按所选时分秒精确计算，不会自动扩展到当天结束。

也可新增一个“日期范围”或“日期时间范围”共享条件，在数据集中分别添加同一日期字段的两个筛选项，将边界设为“范围开始”和“范围结束”，并在每个组件中把两项都绑定到该共享条件。运行页使用一个范围控件联动所有绑定组件；开始不能晚于结束，两个边界均包含在内。日期字段只能绑定日期范围，日期时间字段只能绑定日期时间范围。

时间趋势可将日期或日期时间展示字段设为“按日”或“按月”，再添加求和、计数等聚合指标；例如按月汇总发票申请金额。也可选择“页面共享粒度”，新增“时间粒度”共享条件并在各组件中绑定，运行页默认按日，可切换按月并联动绑定的报表。时间分组采用字段本身的本地时间，不自动进行时区转换；建议同时将分组字段设为升序。所选时间范围只筛选已有数据，不自动补齐没有记录的日期或月份。

筛选项也可以选择“当前用户 ID”“当前用户组织”或“当前租户 ID”，无需再绑定页面条件。可选项取决于字段类型；这些值由服务端从可信身份解析，只能用于等值筛选。当前归属缺失或组织无权时查询会被拒绝，页面参数不能覆盖这些值。

组织类型字段还可选择“当前授权组织列表”，按当前主体可访问的有效组织集合筛选；该集合由服务端确定，客户端不能覆盖。列表为空时查询拒绝，空组织不会被该列表匹配；每个来源自身的租户、领域和组织范围仍单独生效。该能力仍处于安全验收中。

运行页复用项目分析卡片和 ECharts 控件；图表下的“查看数据”可展开结果表。页面条件改变时，已绑定的报表会重新加载，过期请求不会覆盖当前结果。

运行能力启用后，离开报表缓存标签会清除当前结果，再次进入时重新授权加载，筛选条件需要重新选择。可在组件中选择“导出”，勾选需要的列并通过上下箭头调整列顺序。导出按当前共享条件重新请求服务端，重新校验报表菜单和数据范围；文件为 `.xlsx`，文本不会作为公式执行。配置了排行数量的组件按该数量导出；未配置时导出完整结果，超过 5000 条会提示缩小筛选范围，不会静默截断。报表配置在导出期间发生变化时，请刷新页面再重试。

筛选条件或用户上下文变化后，可按新条件重新导出；也可以关闭正在等待的导出对话框。之前请求即使稍后完成也不会下载旧结果。旧请求可能继续在服务端执行，新请求仍受服务端并发限制。

在完成隔离环境验收并启用运行能力后，具备报表更新和菜单创建权限的管理员可在未发布草稿行选择“生成菜单”。系统会创建专用菜单，随后在角色资源权限中勾选具体报表菜单；权限树可用时会同时勾选必要的上级菜单展示权限，不会授予其他报表菜单权限。租户和组织数据范围以及上级菜单的额外授权条件仍需满足。若权限树找不到对应菜单，界面会提示核对上级权限；版本冲突时应刷新列表后重试。

运行能力启用后，具备报表查看权限的超级管理员可在列表选择“预览草稿”，也可在编辑已有报表时选择“预览已保存草稿”。数据集区域的“预览已保存数据”展示已保存草稿中使用该数据集的组件；若没有组件，则自动生成临时表格，按数据集筛选项提供独立条件控件，日期范围的开始和结束分别填写，时间粒度默认为按日。临时表格不保存到报表，预览最多支持 32 个独立条件。预览使用已保存版本，编辑器中的未保存修改需先保存；具备草稿查看权限时，新建或编辑报表均可选择“保存并继续”，之后直接预览，关闭预览后仍可继续编辑。保存后若提示版本已被其他操作更改或读取失败，应关闭并重新打开草稿；保存期间继续输入的修改仍保留在编辑器中。后台重新核对超级管理员身份、报表归属和版本；版本发生变化后应关闭预览并重新打开。平台主体切换租户视角的预览尚未完整支持。

保存请求尚未结束时切换到其他缓存标签，再返回会保留当前编辑内容，但页面会提示重新核对保存结果和草稿版本，并禁止再次提交。等待请求结束后关闭编辑器、刷新列表并重新打开草稿，再确认内容和版本；新建时尤其要先检查列表，避免重复创建。

新建和复制共用频率限制，同一登录令牌七秒内只能提交一次；收到操作过快提示时，输入会保留，可稍后重试。其他请求失败时，页面无法确定服务端是否已创建成功，会保留输入并提示先核对列表；不同令牌或七秒后仍可能产生重复草稿。

运行能力启用后，租户用户在已授权的全局报表页面可选择“复制为租户报表”，填写新报表名称并选择有权访问的组织，创建独立草稿。该操作需要报表新增和数据源目录查询权限；服务端会再次核对全局报表菜单授权，以及来源、字段和关联是否仍在受信目录中。副本不会继承原菜单或发布状态，需到报表设计页面生成菜单、分配权限并发布。权限撤销或来源不可用时复制会失败，不会修改全局原件。

复制请求因连接中断等原因失败时可能已经创建草稿。页面会保留本次输入并阻止当前页面直接重复提交，请先到报表管理列表核对结果；明确收到操作过快提示时可稍后重试。

当前功能仍在建设中：报表管理、菜单生成、预览、复制及运行接口默认均不注册；HTTP 服务已接入权威权限事务，但真实认证、撤权恢复与业务数据范围尚未完成验收，不得用于生产启用。没有绑定真实菜单的报表不能发布；无法安全执行的多表聚合或未适配的枚举和字典范围会被拒绝。不要把布局预览视为真实业务数据预览。

本地体验：在前端工程根目录运行 `pnpm dev:report-preview`，访问 `http://127.0.0.1:5190/`。该工具使用内存中的虚构数据和目录，不连接业务系统、不保存或发布设计，也不执行 SQL；应用设计后，示例关联、字段、筛选、分组聚合、排序和共享条件会作用于本地数据。进入设计器再返回时，原有且类型未变的共享条件会保留；删除后重建或更改类型的条件不会沿用旧值。刷新页面会恢复默认示例。端口被占用时需先释放端口。该工具仅作为开发体验入口，不进入生产菜单。

体验设计器的数据集提供“示例收入 → 示例组织”关联，可选择组织名称并应用设计，查看虚构数据的联表聚合及组织联动；结果不代表真实业务表、权限或正式执行器的行为。

还可继续添加“示例组织 → 示例上级组织”，使用上级组织名称和收入字段体验三来源关联与汇总。

示例收入还提供虚构的“创建人标识”“租户标识”和“所属组织”。可添加筛选项，分别选择当前用户 ID、当前租户 ID、当前组织或当前授权组织列表，观察本地样本变化；这些示例上下文不连接登录用户，不能用于验证真实身份或权限。

示例收入的“结算状态”可用作枚举分组或共享筛选，页面显示“已结算”“待结算”等业务名称；重新设计后若原选择不在新选项内，体验页不会恢复该值。

开发者可在前端工程根目录运行 `pnpm check:report-types` 检查报表设计、运行页面及对应接口，运行 `pnpm check:report-preview-types` 检查隔离体验工具；专项检查不能替代完整应用构建和发布验证。

最小验证：在隔离测试环境显式启用接口后，以有报表管理权限的测试用户打开页面，确认列表和数据源目录可加载；新建草稿并添加字段及组件，检查保存后的列表与版本。以无报表菜单权限的用户核对无法读取报表和导出。按条件导出组件并核对列顺序和结果；真实菜单、业务数据库查询及撤权场景仍需在目标环境验收。
