# 供应商与渠道伙伴页面

> 组织与个人归属以[外部组织主档管理页面使用指南](external-org-master-ownership.md)为准：伙伴主档 `orgId` 是自身外部组织节点，不再设置个人所有者；下文旧“管理组织”表述不适用于新版本。

## 页面入口

在“客户&伙伴”分组进入“供应伙伴”或“渠道伙伴”。两个页面分别维护独立合作关系，同一法律主体可以拥有两类合作关系。

## 新增与编辑

法律主体可暂不选择，也可选择当前账号有权访问的主体；随后填写租户内唯一的完整名称、简称、商务对接部门及合作资料。法律主体名称和证照由法律主体页面维护。所属行业继续支持多值。供应商类型 `type` 单选商品、原材料、配件、一般服务、物流、技术服务、运营、内容与版权或其他；供应短剧成片、剧本、素材或授权知识产权时选择“内容与版权”，拍摄剪辑等劳务选择“一般服务”，平台技术能力选择“技术服务”。渠道类型 `type` 单选经销商、分销商、代理商、线上店铺或线下店铺。客户与合作伙伴的投资关系选项统一使用 `com.levin.oak.base.entities.enums.InvestmentRelation`。

合作关系可独立维护“结算账户信息”（`bankAccount`）和“开票信息”（`invoiceInfo`）；表单按字段填写银行、账号、税号等资料。两组均为可选资料，未选择提交时保留原值；缺失时服务端在独立授权范围内读取法律主体默认资料。结算单仍使用 `payeeBankAccount` 与 `payerInvoiceInfo` 保存角色快照，修改主档不会自动修改已创建的结算单。

供应伙伴与渠道伙伴还可分别维护“对方联系人资料”（`contactInfo`）和“收寄信息”（`shippingInfo`），并设置机密等级与有效期。新增或编辑时，联系人和收寄信息是独立的可选资料组：勾选相应组后填写并提交，未勾选的组不会提交，已有资料保持不变。页面按当前用户字段权限展示和编辑资料，服务端仍会检查对应字段权限及记录范围；没有权限时不能通过提交隐藏字段绕过检查。

最小验证：用有资料权限的账号填写并保存联系人和收寄信息，重新打开检查回显；修改其他字段时不勾选这两组，保存后确认原资料未变。再用无相关字段权限的账号确认资料不可查看或修改。机密等级和有效期按当前记录权限维护，由服务端按各自规则处理。

客户主档的渠道选择器只查询渠道伙伴；开票授权的销方选择器先选择法律主体，再查询该主体的启用供应伙伴关系。提交的值为合作关系 ID，不是法律主体 ID。选择器保留分页与租户切换清空行为。

## 权限与验证

接口按当前登录人的租户、组织和数据范围限制记录；页面可见不代表有权查看法律主体敏感资料。 参与方负责人名称仅在当前用户具备用户列表操作权限，且该负责人属于记录租户内的授权组织并通过字段权限检查时回显；无权或用户不存在时留空，不以用户 ID 代替名称。使用有权限的账号分别新增两种合作关系，检查行业、类型与完整名称回显，并确认客户与发票选择器只能选择各自支持的身份。

旧 Partner 分类与子分类已退出。旧数据不会由页面自动迁移；本次不提供历史数据库迁移 SQL，旧库不可直接作为升级验证环境。

## 合作关系认证

供应伙伴与渠道伙伴页面展示合作关系自身的认证状态；该状态仅供查询和展示，不在新增或编辑表单中修改。依据当前支持事件和接口权限，可执行“提交认证”“认证通过”“认证拒绝”“撤销认证”。拒绝时填写原因，其余操作执行前确认。动作携带合作关系 ID 与乐观锁，成功后刷新数据；冲突或非法事件由服务端拒绝。

“流程日志”沿用当前供应伙伴或渠道伙伴页面的查看详情权限，从对应子类型详情接口读取当前合作关系的服务端日志，按发生时间正序显示操作时间、操作人、原状态与操作及新状态，以及非空备注。合作关系认证独立于法律主体认证，同一法律主体的不同合作关系分别办理。最小验证：提交一条未审核关系，分别验证审核通过或拒绝，再验证已认证关系可以撤销；切换到同一主体的另一关系，确认其认证状态及日志未被修改。
