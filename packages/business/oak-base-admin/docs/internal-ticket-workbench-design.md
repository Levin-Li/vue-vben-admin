# 系统内工单工作台设计

工单沿用已有工单、消息和个人通知模型，同时记录发起组织和受理组织。两个组织属于同一租户，可以不同；发起人按自己的组织和参与资格访问，受理人按受理组织和小组资格访问。授权由服务端逐次检查，前端组织选择和按钮显隐不授予访问权。

发起人和受理人共用列表与对话布局，按当前用户将消息分列左右；内部备注仅受理方可见。工单列表以个人未读状态显示红点，站内消息用于提醒和定位，定位本身不授予工单权限。七秒轮询更新消息，不覆盖未发送草稿。标签可由管理员配置或由用户为当前工单输入。

页面来源仅包含路径和标题；可选截图经用户预览后提交，密码与标记为私密的区域遮盖。截图仍可能含其他业务信息，用户需在提交前检查。超时未解决仅提醒，已解决达到配置天数后自动关闭；状态变更与并发回复由后端锁定和复核。
