# 报表中心前端设计

报表中心将数据集、共享条件和页面组件组合为声明式设计。设计器按来源、关联、字段统计和筛选组织配置，并提供明确标识的虚构示例预览；真实数据预览只针对已保存草稿。

报表菜单是授权单位，获得权限的用户可以查看全部输出字段。前端隐藏入口和输入校验用于改善体验，服务端仍负责身份、菜单、字段白名单及每个来源的数据范围。多表左连接中不可见的右侧记录显示为空；无法安全汇总的粒度须由服务端拒绝。

运行页提供共享筛选、图表及表格，支持数据导出和页面级撤权处理。布局、图表和金额展示的操作说明见[使用指南](report-center.md)。管理和运行接口默认关闭，生产认证及业务范围仍需验收。
