# 结算单多方页面实现说明

`settlement-order/index.vue` 提供独立页面入口，`config.ts` 显式维护字段、表单和操作配置，`api/settlement-order-service.ts` 声明与业务控制器一致的请求和结果类型。列表调用 `listByRoles`，销售、财务与收款方组织和人员筛选只收窄服务端授权范围。新增请求携带伙伴、付款/收款方、付款方销售/财务及收款方组织、可选人员；编辑请求只发送原单可修改的时间和结算内容，不发送新归属。

关联选择器使用现有组织、用户、伙伴和法律主体选项入口。列表、详情、查询与表单按同一后端字段契约回显；敏感组仍由 `readFinancialDetails` 提供，普通列表响应不作为敏感资料来源。流程按钮使用当前服务端支持事件和接口权限，不从付款/收款方身份自行放行。

最小验证：分别创建伙伴付款与伙伴收款的结算单，确认列表和详情回显；待确认编辑后检查归属未变；用销售、财务和无关用户检查摘要与财务资料边界；登记分笔打款并核对上传文件资源所用财务组织。
