# 租户站点登录组织范围

在“租户站点管理”新增或编辑站点时，“登录组织范围”可以留空，也可以选择站点所属租户的组织。维护该字段需要租户站点的相应新增或编辑权限；请先确认站点绑定的租户和域名正确。

留空时不增加组织限制；选择组织 A 后，仅 A 及其任意下级组织的租户用户可从该域名登录。平台账号不受此组织限制，用户自己的登录域名白名单仍生效。组织范围不会改变用户的角色或数据权限。旁支、无组织、停用或异常组织链会被拒绝，登录提示为 `用户名或密码错误-<当前站点域名>域名`；站点组织变更后，已有会话在下一次请求时也会重新检查。

最小验证：在隔离环境给站点选择组织 A，用 A、A 的下级和旁支 B 用户分别登录，确认前两者通过、B 被拒；然后清空该字段，确认恢复原有租户和域名白名单规则。生产站点变更前应保留可恢复的管理入口。
