# 新租户管理员创建指南

## 入口与前提

安装并注册 `@levin/oak-base-admin` 后，在平台“租户管理”页面点击“新增”。当前账号须具有平台租户“新增”权限。管理员首次登录前，须为新租户配置实际访问域名，并通过受控渠道交付账号及口令。

## 填写与提交

除租户资料外，创建表单要求填写“管理员初始口令”。新管理员的 `loginName` 默认是 `admin`，页面无需输入登录名，系统也不从租户资料生成邮箱。初始口令须为 6 至 128 字符，同时包含大写英文字母、小写英文字母和数字；可使用特殊符号。页面提交前提示错误，后端再次校验。口令字段只在新增时显示，编辑租户不能借此修改管理员凭据。

登录名在同一租户的用户表内须唯一，不要求全局唯一；不同租户都可以使用 `admin`。登录时通过已绑定域名确定租户。

页面调用 `POST /Tenant/createWithAdmin`，请求字段为 `adminInitialPassword`。成功后返回管理员用户 ID，租户、根组织、角色和管理员在同一事务中创建；口令不会在响应、列表或详情中显示。校验失败时不会创建租户，按字段提示修正后重试。

## 最小验证

在隔离环境输入唯一租户资料和 `Ab1234`，确认前端允许提交且新管理员登录名为 `admin`。将口令改为 `Ab123` 以下的五字符值，或改为缺少数字的值，确认表单阻止提交并显示对应规则。管理员登录时使用新租户已绑定的域名。
