# 外部组织主档管理页面使用指南

## 入口与前置条件

在后台“客户&伙伴”分组进入“法律主体”“客户”“供应伙伴”或“渠道伙伴”。创建客户或伙伴主档时可直接填写业务资料：可选择有权访问的内部组织作为新外部组织的父级；不选时服务端回退到当前登录用户所属的内部组织。服务端在同一事务中创建对应类型的外部组织和业务主档；没有有效内部父级时保存失败。法律主体可暂不关联，后续在编辑中补全。页面操作以当前用户的资源动作权限、组织范围和主体资料权限为准。

## 页面字段与操作

- 法律主体页的组织是“添加/管理组织”，一个组织可管理多个主体。页面不设置个人所有者；同租户规范化证件号重复时创建失败。
- 新增表单的“内部父级”只列出公司、分公司、部门、团队、小组和临时组织；所选 `orgId` 仅作为新外部组织的父级，不能选择已有外部节点。保存后主档的 `orgId` 是新建的自身外部组织节点，编辑页只读显示该节点，不可更换。一个节点最多建立一条对应主档。
- 新增客户时，无论是否选择内部父级，都须填写“客户名称”，服务端用该名称创建客户组织。新增供应或渠道伙伴时，以必填的“业务名称”创建对应组织。
- 法律主体可留空；列表与详情显示“待完善”。之后可在编辑页面选择有权访问的同租户法律主体；已关联的主体不可更换。签约、开票、结算等需要法定身份的业务动作须先补全主体；未补全时以服务端错误为准。
- 客户类型可选直接客户或渠道客户；渠道客户还须选择可访问的渠道伙伴。供应与渠道类型分别在自己的页面选择。
- 主体或伙伴认证使用页面提供的专用状态动作，并以服务端返回的可执行事件和动作权限决定显示；普通表单不能直接改写状态。

## 结果与最小验证

创建成功后，列表和详情应显示实际外部组织；编辑不能更换组织。选择外部组织、跨租户主体、组织与主体不一致或越权时，以服务端错误为准，页面不得当作成功。可在测试租户分别选内部父级和留空创建客户、供应和渠道记录，确认父级选择优先于登录用户所属组织，留空时正确回退；随后补全法律主体，并确认编辑页显示新建外部节点且不能更换。

历史页面展示设置可能保存已移除的 `ownerId` 或旧组织标题；本版本不会借页面读取静默修改这些设置。存量主档的 `orgId` 迁移应由后端发布批次显式处理，不能只升级前端包。
