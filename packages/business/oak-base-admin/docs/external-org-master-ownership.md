# 外部组织主档管理页面使用指南

## 入口与前置条件

在后台“客户&伙伴”分组进入“法律主体”“客户”“供应伙伴”或“渠道伙伴”。创建业务主档前，须有本租户可访问的法律主体和相应类型的外部组织节点。组织尚未关联主体时，创建主档会由服务端同事务建立关联；已关联其它主体时保存失败。页面操作以当前用户的资源动作权限、组织范围和主体资料权限为准。

## 页面字段与操作

- 法律主体页的组织是“添加/管理组织”，一个组织可管理多个主体。页面不设置个人所有者；同租户规范化证件号重复时创建失败。
- 客户、供应伙伴和渠道伙伴页的组织是主档自身的外部节点，分别只选择 `Customer`、`SupplierPartner`、`ChannelPartner` 类型。一个节点最多建立一条匹配主档；组织和法律主体创建后只读，不能在普通编辑中换绑。
- 客户类型可选直接客户或渠道客户；渠道客户还须选择可访问的渠道伙伴。供应与渠道类型分别在自己的页面选择。
- 主体或伙伴认证使用页面提供的专用状态动作，并以服务端返回的可执行事件和动作权限决定显示；普通表单不能直接改写状态。

## 结果与最小验证

创建成功后，列表和详情应显示所选外部组织；编辑不能更换组织。选择不匹配的组织、重复创建、跨租户主体、组织与主体不一致或越权时，以服务端错误为准，页面不得当作成功。可在测试租户分别创建一条客户、供应和渠道记录，再对同一组织重复创建，确认服务端拒绝且原记录不变。

历史页面展示设置可能保存已移除的 `ownerId` 或旧组织标题；本版本不会借页面读取静默修改这些设置。存量主档的 `orgId` 迁移应由后端发布批次显式处理，不能只升级前端包。
