# Published Frontend Rules AGENTS.md

<INSTRUCTIONS>
本文件适用于随包发布的 `docs/frontend-rules/` 目录。源码工作区不固定保存前端模块规则副本;打包和发布流程会按需临时写入 `前端模块开发规则.md`，并在结束后清理。

## 必读规则

按任务类型读取对应专项规则:

- 前端模块总规则、浏览器验证、打包和发布规则: `前端模块开发规则.md`
- 页面开发、布局、组件、主题和CRUD页面: `前端页面开发规则.md`
- API封装、接口请求、服务层调用和后端接口对接: `前端API开发规则.md`
- 页面操作、按钮、动作归属和交互流程: `前端页面操作规则.md`
- 表单校验、字段校验和提交前校验: `前端页面校验规则.md`
- 上传组件、文件选择和资源上传: `前端页面上传规则.md`
- 部署代理、开发代理和接口转发: `前端部署代理规则.md`

## 执行要求

- 涉及多个主题时必须同时读取对应专项规则。
- 页面视觉、交互、路由、下载和浏览器现场问题优先用当前 in-app browser 验证；如果 in-app browser 不可用，可使用补充验证，但必须明确标注不能代表用户当前浏览器现场。
</INSTRUCTIONS>
