# 独立客户页面使用指南

## 入口与前置条件

启用 `@levin/oak-base-admin` 后，在后台“客户&伙伴 → 客户”进入 `/clob/V1/Customer`。当前用户需要客户管理权限及对应租户、组织的数据范围。创建前先在“法律主体”页面建立可访问的主体；客户页面不会代为创建法律主体。

## 操作与字段

1. 新增客户时搜索并选择法律主体、管理组织，选择“直接客户”或“渠道客户”，可填写所有者。渠道客户还必须从当前有权访问的启用渠道合作关系中选择渠道伙伴；直接客户不提交渠道伙伴 ID。客户拥有独立 ID，同一法律主体可同时对应客户及渠道、供应链合作关系。
2. 在客户侧独立填写联系人姓名、电话、邮箱，以及客户等级、行业、机密等级、分组、投资关系和有效期。修改这三个联系人字段不会同步修改法律主体的联系人。
3. 列表可以按客户 ID、法律主体、类型和运营字段查询；打开详情可查看主体名称。编辑时法律主体、客户类型、管理组织、所有者及渠道伙伴保持只读。若需改变身份，应按业务规则处置旧记录，再建立新客户记录。

保存使用 `/Customer/saveCustomer`，更新使用 `/Customer/updateCustomer`；列表和详情使用 `/Customer/list`、`/Customer/retrieve`。默认删除与批量写入入口不开放。选项搜索和关联主体详情均受服务端权限控制。跨租户、超出数据范围、重复生效客户关系或更改不可变关联字段会被服务端拒绝；页面只读约束不能代替服务端校验。

最小验证：使用有权访问的法律主体分别创建直接客户和渠道客户，确认两条记录的客户 ID 独立于主体 ID；修改一条客户联系人，确认另一条客户及法律主体联系人不变；尝试重复创建同租户、同组织、同主体、同类型的生效客户关系，应收到拒绝。已有 `Partner.Customer` 历史数据不会自动转换，本功能不提供迁移 SQL。
