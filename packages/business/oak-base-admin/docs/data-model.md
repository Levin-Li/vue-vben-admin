# 领域数据动态模型与动态数据页面

实体类为 `DomainDataDynamicModel`，管理页的规范链接为 `/clob/V1/DomainDataDynamicModel`，页面目录为 `views/domain-data-dynamic-model/`。查询、列表、新增、编辑、详情和界面展示设置统一使用公共 `DynamicCrudPage`；字段维护、结构预览和同步是该页面的业务扩展。实际HTTP调用继续使用已有 `DataModel` 安全业务API，不能通过开放生成实体的透传CRUD替代归属、版本和发布检查。

升级已有菜单时，应在部署批次中显式迁移旧菜单路径及视图位置；不注册旧页面路径别名，也不在运行时自动改写菜单或展示设置。

“开发&工具 → 领域数据动态模型”用于维护领域模型定义。先在基础信息表单填写稳定标识、名称、中文标题及归属范围并保存；新模型可以暂时没有业务字段。随后从模型行进入“字段管理”：默认先列业务字段，“字段来源”可切换全部、模型属性或记录系统列；全部视图仍把业务字段排在前面。主表仅显示来源、属性名、中文标题、类型、数据权限组、用途摘要与操作；“查/列/新/改/详”分别代表查询、列表、新增、编辑和详情。业务字段可按行新增、编辑或删除，描述、可空、完整用途开关、类型参数、默认值和选项在行编辑弹窗中维护；系统字段只读，由服务端基础实体描述生成，不提供文案编辑或删除。字段清单保存携带当前定义版本，版本过期时须重新打开。基础信息保存不覆盖字段，两类保存都不执行建表。定义至少一个业务字段后，打开“预览差异”检查 SQL 和风险，再执行安全同步。已同步且启用的模型可从“打开页面”进入按目录字段运行时生成的记录列表、表单和详情；重新同步后再次进入会读取新目录，无需重新构建前端。

“领域数据动态模型”JPA 实体使用独立主键 `id`；`modelKey` 是模型的稳定业务标识。每个接口由“领域数据动态接口”JPA 实体独立表示。模型标识和字段稳定标识使用 1～48 位小写 ASCII 字母、数字、下划线；属性名支持受限 camelCase，物理列由项目既有命名策略生成并检查碰撞，首位均为小写字母；创建后稳定标识不得更改。基础字段与标准实体对应，涵盖 ID、平台领域、租户、组织、所有者、创建人、创建/更新时间、启用、可编辑、排序、备注和乐观锁；定义另保留共享标志与派生公开状态。标准属性使用 `domainId`、`tenantId`、`orgId`、`ownerId`、`createTime`、`lastUpdateTime`、`enable`、`optimisticLock` 等，页面不提供额外映射列。字段管理将模型属性和记录系统列都列在表格中，不保存逐模型文案覆盖；字段名称、类型和说明以服务端定义为准。

字段支持字符串、长文本、整数、大整数、精确小数、金融金额、布尔、日期、时间、日期时间、UUID 和 JSON。精确小数、金融金额及大整数使用文本输入，避免 JavaScript 数值精度丢失。固定选项以有类型的 `value` 和中文 `label` 定义；枚举和字典通过服务端引用加载。字段输入仍由服务端按已同步定义验证。

字段管理可分别设置“允许查询”“列表展示”“新增表单”“编辑表单”“详情展示”。查询操作符按字段类型限制：字符串/长文本支持等于和包含；整数、大整数、小数、金额及日期时间支持等于和大小比较；布尔与 UUID 只支持等于；JSON 暂不参与查询。同步后，运行时页面才使用这些新配置。查询由服务端按已同步字段白名单、操作符和可信数据范围执行，前端条件不能放宽记录权限。

字段管理可创建模型内稳定的数据权限组，设置标题、说明和现有 RBAC 机密级别，再为业务字段选择权限组。未分组业务字段仍受模型动作及可信行范围约束；已分组字段还需服务端核验对应操作的字段组授权。字段组和字段引用在同一次版本化 `saveFields` 中保存；系统归属字段始终属于受保护的系统范围，不由此处改组。目录、查询、列表、表单与详情的实际字段候选以服务端按当前身份裁剪后的同步契约为准。

新增记录由页面生成 UUID 请求键；同一表单内容因响应丢失而重试时复用该键，服务端仅写入一次。同一键携带不同内容会被拒绝，修改表单内容后页面生成新键。

动态记录页复用公共 CRUD 布局与表单控件，日期时间保存为带时区的 ISO 8601 值；编辑其它字段不会改写未修改时间的秒及小数精度。模型默认值按字段类型进入新增表单；枚举、字典的具体可选值由模型目录返回，列表与详情按有类型的值显示标签。目录及记录 API 前端仅要求登录，动作入口消费后端 `operations.authorized`，不额外要求旧通用动态记录权限。服务端仍执行动作、字段白名单及领域/租户/组织/个人范围校验。

独立动态页面直接采用公共 DynamicCrudPage，“界面展示设置”按稳定模型 ID 保存为 `PageDisplay`。字段显隐、顺序、标题、列宽、分组、查询和表单行为遵循公共 CRUD 规则；设置只作用于当前主体和接口允许的字段，不会扩大服务端读写权限。无效旧字段键忽略，模型升级命名后应核对原有展示覆盖。编辑先读取 EDIT 接口字段和完整记录，详情使用独立详情契约。

编辑、启停和永久删除都携带当前记录的 `optimisticLock` 作为顶层 `expectedVersion`。服务端使用版本与最终数据范围共同校验，编辑/启停成功后原子递增版本。版本冲突应重新读取并核对修改内容，页面不自动覆盖别人已保存的值。记录行“永久删除”会展示不可恢复提示与删除确认，删除后列表与详情不再显示该记录；记录存在期间，同一请求键重试仍按服务端去重；记录永久删除后，不承诺旧请求键继续占用。

不再提供独立的通用模型目录菜单。使用者从具体模型的业务菜单进入记录页；模型定义管理仍要求管理权限。平台领域使用现有已验证上下文与数据权限分配，不能从 Host 或用户归属领域自行推断；切换领域后重新加载目录及记录。空领域对象沿用标准领域对象的公开语义，非空领域的允许/拒绝限制由服务端执行。

已同步且启用的模型可从模型行点击“生成菜单”。后端为每个模型在“开发&工具”下生成独立菜单项，重复点击返回同一菜单；菜单固定参数仅用于定位模型，同一通用记录页面从已同步目录运行时生成查询区、列表、表单和详情。生成成功后页面重新加载导航。停用模型后菜单可保留，但页面会显示不可用，记录 API 也拒绝访问。

模型行“接口管理”维护标准查询、新增、更新、删除，以及详情、启停和扩展接口。每个接口显式展示标准/扩展分类、动作类型、HTTP 方法与真实路径；请求和响应定义按完整 JSON 保存，不拆成参数表。标准动作的身份和对象/记录级别固定，中文标题、启用状态与允许参数可配置；查询、新增是对象级动作，更新、删除和详情是记录级动作。没有或未启用的接口不显示对应按钮。接口管理同时提供请求/响应字段候选、固定查询条件和固定赋值表格，保存后通过安全同步发布。

查询条件的字段与操作符在查询接口中确定，运行页面只显示条件标题及值输入框，不让使用者选择比较方式。请求使用 `queryValues.<查询键>`；新增/更新业务字段使用 `values.<字段名>`，归属字段使用独立的 `scope`。新增/编辑打开时通过 `formContext` 获取当前用户有权使用的字段、默认值和引用候选，本地展示设置只能进一步调整这些字段。租户、组织、所有者和平台领域使用授权候选，组织和所有者复用公共选择器；创建默认来自可信当前用户与上下文。租户和平台领域不能通过普通编辑改变，组织和所有者调整仍受既有管理员与目标范围校验。无须用户输入的系统字段不会堆在新增/编辑表单中，详情可折叠查看基础信息。

记录级自定义动作支持界面配置固定字段更新，例如把状态改为指定枚举值；固定金额使用精确字符串。对象级自定义动作支持按预设字段快速创建，并可补充接口允许的其它输入。执行仍校验该动作权限、读写字段组、记录范围和乐观锁；创建使用请求键去重。自定义动作不接受 SQL、脚本或任意外部执行地址。

角色授权界面使用现有 RBAC 权限树中的模型资源动作；每个模型分别授予操作及所需字段组。动态页从后端当前主体的模型操作状态决定按钮可见性，菜单可见和界面展示设置都不授予接口权限；实际调用仍由后端重新检查模型动作与数据范围。

模型字段、操作和查询元数据按模型版本缓存。前端使用 20 秒、最多 256 项的内存缓存并合并同时请求，缓存键隔离当前用户、平台领域、租户、组织及权限版本；模型、字段、接口保存与同步、记录写入和归属上下文变化后失效，写入开始和结束均失效，已失效的在途请求不会回填旧值。界面展示设置沿用公共设置加载机制，并按相同上下文短时缓存。编辑每次先实时读取记录，表单元数据按记录 ID、版本及完整归属参数区分；归属变更后重新获取候选。后端缓存保存不可变定义快照，每次请求仍读取模型状态与版本并校验当前权限；不缓存业务记录授权结论。

创建时必须明确选择当前可用的平台、租户、组织或私人归属；页面不预选归属。私人归属默认当前用户。管理员可从已有用户选项中指定私人模型所有者；服务端验证管理员权限、用户存在及归属关系。归属层级创建后不可通过普通编辑改变。平台模型的 `tenantId` 为空，自动向所有租户公开定义；租户模型的 `orgId` 为空，自动向本租户公开定义。这些公开状态由归属 ID 推导，没有独立开关。非空租户归属可选择跨租户共享，非空组织归属可选择跨组织共享。所有共享只扩大模型定义和字段的可见性，既有业务记录仍受租户、组织和个人范围隔离。跨租户使用字典字段时，选项按当前使用者的可信租户解析。最终归属、共享授权及记录范围由服务端判定。

模型默认启用。列表显示服务端创建时间和启用状态；专用“停用/启用”操作保留定义和物理记录。停用期间模型不出现在可用目录，动态记录接口拒绝访问，重新启用后记录仍在。

预览出现风险时页面禁用同步。删除字段、收缩长度、更改类型等损失数据的变更需另行审计迁移，不通过此页面执行。同步请求携带预览的定义版本和结构指纹；模型定义或物理结构变化后应重新预览。失败时保留错误并重新检查实际数据库结构。

最小验证：先保存一个空字段模型，确认列表出现创建时间且无法同步；从“字段管理”新增 `MONEY` 字段并保存，确认基础信息编辑不会删除字段；预览安全建表 SQL 并同步；在动态数据页输入大额十进制金额，保存后读取确认精度。停用模型后确认“打开页面”入口消失，重新启用后记录保留。请仅在独立测试数据库进行物理结构同步验证。

## 简单工作流嵌入与查询匹配

动态领域模型主要承载简单业务数据，可按稳定模型标识供工作流嵌入表单和操作引用。查询接口中逐项配置目标字段和匹配逻辑，例如名称包含、状态等于、金额下限/上限。日期、时间、日期时间均可配置起止范围，含边界时分别使用大于等于与小于等于；也可只填写一端。运行页面只输入值，不选择操作符；日期时间使用带时区值，时间保留支持的秒及小数精度。接口定义保存后同步发布，查询始终叠加当前数据权限。

租户、组织和平台领域采用与公共 CRUD 一致的授权下拉选择；组织复用公共选择器。字段是否展示由 UI 设置决定，默认隐藏租户和平台领域，管理员可在已开放字段范围中显式显示或隐藏。隐藏字段继续遵循可信上下文默认处理，不自动提交空值；UI 设置不会开放接口未允许的归属修改。

## 领域模型定义管理

“领域模型定义”直接使用公共 DynamicCrudPage：模型标识、名称、标题、启用状态与创建时间范围构成查询面板，查询及回车从第一页执行，重置恢复输入默认值但不立即查询。列表支持分页、允许列排序、刷新、全屏、列设置与导出；列设置可调整显隐、顺序和固定位置，取消时恢复原状态，导出按选择的字段和顺序生成当前查询结果。字段管理、接口管理、预览/同步和生成菜单属于额外行操作。

通用目录入口已移除，不再展示模型选择表格；无模型参数时不请求目录。已有具体模型入口仍按当前身份、模型同步和启用状态取得授权定义，真正权限或归属变化仍重新校验。

定义管理页直接展示标准查询与列表，行“打开页面”提供真实独立动态记录页链接。生成菜单的固定模型参数及经格式校验的 URL 模型标识都只负责定位，记录字段和权限从后端目录加载。

定义管理页与动态记录页都直接采用公共 CRUD 渲染器。定义页按管理接口配置，动态记录页由后端字段和动作元数据生成配置；查询、表格工具、表单和界面设置使用同一套处理。
