# 用户管理重置密码使用指南

在“用户管理”页面找到目标用户，在该行“操作”中选择“重置密码”。输入新密码和确认密码后提交；密码需为 6 至 128 字符，包含大写字母、小写字母和数字。保存成功后目标用户已有会话失效，须用新密码重新登录。新增用户可在新增表单设置初始密码；普通编辑表单不修改密码。

按钮仅对管理员且具有“重置密码”接口权限的用户显示，且不在本人记录上显示；普通用户即使能打开用户列表也看不到该操作。服务端再次检查管理员身份，并核验目标的租户、组织、领域、机密等级及角色权限；前端按钮可见不代表最终授权。失败时弹窗保留输入供修正，关闭有未保存输入的弹窗会提示确认放弃。密码不会出现在详情、列表或成功提示中。

前端沿用 RBAC 接口的默认路径规则，将本模块 `/User/*` 和 `/Org/*` JSON API 主动加密；公共请求层使用现有 URL ACL AES-GCM 加密请求并处理加密响应。重置密码、新增用户及 MFA 凭据方法不向通用请求事件总线广播凭据内容。服务端另行对登录密码做单向编码。最小验证可在浏览器网络面板确认重置密码、更新用户和更新组织请求带 `X-UrlAcl-Crypto-Algorithm: AES_GCM`、请求体为密文，并在目标有权与无权场景确认保存和拒绝结果；不要把密码明文、密文或令牌复制到工单与日志。
