# 文档中心使用指南

## 入口与适用对象

登录管理后台后，在右上角用户下拉菜单选择“文档中心”。可按模块、读者类型和关键词查找随当前前端包发布的使用手册、使用指南、开发指南和实现说明。客服工单、支持邮箱受理规则和根域名管理页面也有“帮助”按钮，可直接打开对应说明。文档地址中的 `doc` 是稳定文档 ID，章节标题可通过 URL 片段定位。

“用户”“管理员”“开发者”是阅读用途分类，不是权限授权。前端静态资源可能被直接获取，因此不可在这里登记密码、私钥、未公开的部署信息、迁移记录或其它受限材料。需要严格按角色保密的文档应另由后端鉴权交付。

## 文档登记与命名

新文档统一放在源仓库的 `docs/help/<模块>/`，文件名采用 `<功能>-<类型>.md`，类型沿用发布白名单中的“使用手册”“使用指南”“开发指南”或“实现说明”，例如 `docs/help/mail-ticket/工单处理-使用手册.md`。操作手册归“使用手册”，管理员配置归“使用指南”并把读者登记为“管理员”。已有文档可保留原路径，逐步整理，不为满足新命名规则批量改名。

在线文档由包根目录的 `help-center.catalog.json` 显式登记：

- `id`：稳定、唯一的小写短横线标识，发布后不能随标题改名。
- `title`、`module`、`audience`、`type`：供目录展示和筛选；分类以登记值为准，不按文件名猜测。
- `source`：相对于后端项目根目录的 Markdown 路径，或本前端包 `docs/` 下的路径。
- `pages`：可选的业务路由与真实页面目录，用于就地帮助关联。

登记文件须是允许随包交付的非机密说明。构建检查 ID、来源、类别、页面和相对链接；已登记的文档间链接转换为文档中心地址，存在但未登记的内部资料只保留文字说明，不生成失效链接。原始 HTML、脚本和危险 URL 不会作为可执行内容显示。文档内容随包版本冻结；在线修改源 Markdown 不会影响已部署版本。

## 构建与最小验证

从 `frontend/admin` 执行 `node scripts/generate-help-center.mjs` 生成正文和 `manifest.json`，执行 `node scripts/generate-help-center.mjs --check` 核对生成产物。`@levin/oak-base-admin` 的正常 `build` 命令会自动生成。打包后应检查 npm tarball 中的 `src/modules/com_levin_oak_base/help-content/` 和对应 `dist/` 文件，并在运行中的管理后台打开菜单、业务页帮助和章节直达地址。

目录记录稳定 ID、来源路径和章节地址，可用于后续 AI 回答引用原文；当前版本没有 AI 问答入口。若需增加 AI 功能，应另行定义检索范围、权限、引用和错误处理契约。
