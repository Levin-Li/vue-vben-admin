# 快捷添加客户与伙伴开发指南

## 接入入口

安装并注册 `@levin/oak-base-admin` 模块后，使用已有“客户&伙伴”分组下的客户、供应伙伴、渠道伙伴页面；无须新增业务路由。宿主需提供后端 `API_PATH`、当前用户权限上下文和列表请求能力。三个 `quickAdd` 请求分别固定对应资源，不能仅在前端传一个自由目标类型模拟其它资源操作。

请求使用 `QuickAddPayload`：`legalSubjectName`、`subjectType`、`creditCode`、`shortName`、`telephone` 必填；`adminName`、`loginName`、`password` 可选；供应和渠道另分别提交 `supplierType` 或 `channelType`。成功的 `QuickAddResult` 含 `orgId`、`legalSubjectId`、`userId`、`businessId`、实际 `loginName`。不要提交租户、父组织、角色或负责人字段，也不要把工商搜索结果当成已认证主体。错误由接口返回，页面应保留草稿。

## 扩展边界

接入新的业务身份时，应先定义后端受权控制器操作与事务目标，再在对应页面和 API service 增加入口；`quick-add.vue` 的目标分支、子类型校验和 `listOperations` 登记要同步更新。改变搜索供应商时，仍需遵守“候选搜索与选中后详情分开调用”，并在页面明确计费与不可用处理。快捷按钮的权限元数据需与后端 `@CRUD.Op` 动作一致，不能只靠 UI 隐藏限制调用。

本包的公开安装入口和二次开发约束见[模块开发规范](MODULE-DEVELOPMENT-STANDARD.md)。包内 `src` 便于阅读和调试；下游应用依赖已发布的 `dist` 导出，不直接引用 `src` 参与编译。

## 最小验证

用具有相应动作权的测试账号在三页分别打开弹窗，确认按钮与必填子类型；以人工补录完成一次客户开户，检查返回的登录名和列表刷新；用同一主体跨身份建档，再对同一身份重复提交，确认明确拒绝且数据库无部分记录。另用无搜索权限账号核对人工路径可用、无快捷添加权限账号核对按钮与接口拒绝。正式启用搜索前核对供应商配置和计费。
