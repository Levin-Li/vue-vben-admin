# 快捷添加客户与伙伴开发指南

## 接入入口

安装并注册 `@levin/oak-base-admin` 模块后，使用已有“客户&伙伴”分组下的客户、供应伙伴、渠道伙伴页面；无须新增业务路由。宿主需提供后端 `API_PATH`、当前用户权限上下文和列表请求能力。平台用户除快捷添加动作权限外还需 `Tenant/list` 与 `Org/list` 读取权限；缺少候选读取权限时页面不展示可用的快捷添加入口。三个资源分别提供管理员 `quickAdd` 和普通用户 `quickAddMine`，不能仅在前端传一个自由目标类型模拟其它资源操作。

请求使用 `QuickAddPayload`：`legalSubjectName`、`subjectType`、`creditCode`、`shortName`、`loginAccount` 必填；`adminName`（页面“用户名”）可选；`password` 对普通登录名必填，对手机号或邮箱可选；供应和渠道另分别提交 `supplierType` 或 `channelType`。平台用户还必须提交明确选择的 `tenantId`；所有用户均提交本人有权访问的主体方组织 `parentOrgId`，它也是外部组织的父级。切换租户须清除旧组织。不再提交 `telephone` 或独立 `loginName`。成功的 `QuickAddResult` 含 `orgId`、`legalSubjectId`、`userId`、`businessId`，以及兼容回显实际登录账号的 `loginName`。不要提交角色或负责人字段，也不要把工商搜索结果当成已认证主体。错误由接口返回，页面应保留草稿。

## 扩展边界

接入新的业务身份时，应先定义后端受权控制器操作与事务目标，再在对应页面和 API service 增加入口；`quick-add.vue` 的目标分支、子类型校验和 `listOperations` 登记要同步更新。公共 CRUD 的 `toolbar-before-create` 插槽用于将快捷按钮置于默认新增前；保持与新增按钮一致的主按钮、加号图标和高度，其他页面仍沿用原工具栏顺序。改变搜索供应商时，仍需遵守“候选搜索与选中后详情分开调用”，并在页面明确计费与不可用处理。快捷按钮的权限元数据需与后端 `@CRUD.Op` 动作一致，不能只靠 UI 隐藏限制调用。

本包的公开安装入口和二次开发约束见[模块开发规范](MODULE-DEVELOPMENT-STANDARD.md)。包内 `src` 便于阅读和调试；下游应用依赖已发布的 `dist` 导出，不直接引用 `src` 参与编译。

## 最小验证

用具有相应动作权的租户用户和平台用户在三页分别打开弹窗，确认快捷按钮置于新增前并与其外观一致、伙伴子类型仍必选；平台用户选择租户，所有用户选择可访问的主体方组织；切换租户须清空旧组织，跨租户或无权组织应拒绝且无部分记录。以人工补录分别用手机号、邮箱和普通登录名完成开户，检查返回的登录账号、默认或自定义用户名和列表刷新；普通登录名不设密码须在写库前拒绝。用同一主体完整名称跨身份建档，以及对同一身份重复提交，均应明确拒绝且数据库无部分记录。另用无搜索权限账号核对人工路径可用、无快捷添加权限账号核对按钮与接口拒绝。正式启用搜索前核对供应商配置和计费。
