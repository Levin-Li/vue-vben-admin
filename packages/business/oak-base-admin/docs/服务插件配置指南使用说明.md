# 服务插件配置指南使用说明

## 入口与用途

在管理后台的“服务插件设置”或“租户插件设置”中，选择一条供应商配置，点击“编辑供应商配置”，再点击弹窗右上角“配置指南”。指南在当前配置弹窗右侧打开；关闭后可以继续填写和保存配置。

指南先列供应商主站或服务入口、配置入口或官方文档，再列准备条件、配置步骤及补充能力说明。服务插件没有外部供应商，或尚无可核实的官方入口时，指南显示本系统及部署环境中的配置说明，不提供猜测的外链。

## 配置步骤

1. 打开指南中的供应商主站或服务入口，确认账号、产品和所需接口权限。涉及实名、资质审核、费用、回调地址或 IP 白名单时，先按供应商要求完成。
2. 打开配置入口或官方文档，按当前插件实际能力创建应用及最小权限凭据。若指南没有外部链接，以页面字段说明和部署文档为准；不要把其它供应商的入口当作当前配置入口。
3. 按当前表单字段和指南要求保存敏感凭据。支持部署引用的字段应在受控部署环境保存实际值，并在表单填写 `env:变量名`；不要在备注、文档或工单中填写明文密钥。部分存量插件字段仍直接读取配置值，正式启用前应核对其存储和脱敏边界。
4. 保存配置并按插件支持的方式验证。仅显示“已启用”不代表供应商账号已开通、额度充足或真实调用成功。

OAuth 供应商指南中的回调地址根据当前站点和实际 API 路径显示，可通过指南内按钮复制；仍需在供应商控制台登记并实测。切换供应商后，应重新打开指南，以免使用上一家的配置说明。

## 权限、结果与最小验证

只有具备相应插件配置权限的管理员可进入配置弹窗；指南中的链接只指向代码声明的可信 HTTPS 地址。指南不展示或解析已保存的密钥。若官方链接不可用或供应商产品已调整，应以供应商当前官方控制台与合同权限为准，更新插件元数据后再配置。

最小验证：分别打开一个有官方链接的供应商和一个本地插件，确认“配置指南”均可见；检查链接位于步骤上方、链接指向所选供应商、步骤与表单字段一致。百度 OCR 的“当前插件能力”应显示为列表，不应出现原始 Markdown 表格竖线。
