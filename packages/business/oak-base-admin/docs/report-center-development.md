# 报表中心前端开发指南

下游项目应通过本包声明的公开入口集成报表页面和接口，并遵循[模块使用与二次开发规范](MODULE-DEVELOPMENT-STANDARD.md)。不要依赖未公开的内部组件路径、通过前端条件代替服务端授权，或将示例预览结果当作业务数据。

服务端目录负责提供受信来源、字段及关联；页面只能配置已登记项目，不能提交 SQL、脚本、主体或授权范围。扩展字段、关联或聚合时，应同时核对服务端数据类型、每来源数据范围、左连接空值和聚合粒度。报表整体授权不包含字段脱敏，输出字段需由管理员审核。

接入或升级后至少验证菜单授权及撤权、身份切换时的过期响应、草稿版本冲突、已保存数据预览、导出上限和多表数据隔离。接口当前默认关闭；创建和复制对同一登录令牌共用七秒 Redis 限制，429 响应可稍后重试；连接中断等结果不确定时应先核对列表，不得将其视为跨客户端持久化去重。
