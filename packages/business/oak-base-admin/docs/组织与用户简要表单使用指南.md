# 组织与用户简要表单使用指南

## 入口与前置条件

在“基础框架 → 用户&权限 → 组织与用户”打开组织树与用户列表。用户须分别具备组织或用户新增、更新权限；分配角色还须具备独立的“分配角色”权限。左侧先选择有权访问的组织，右侧用户列表按该组织查询。

## 组织新增与编辑

组织树顶部“新增”创建根级组织，节点右侧“新增下级组织”预填上级组织；节点右侧“编辑组织”读取目标详情。弹窗默认显示简要表单：上级组织、组织类型、组织类别、组织名称及备注。组织名称与类别须填写；平台用户新增根组织时仍须选择归属租户。点击“更多”展示原有组织编码、简称、排序、启用与可编辑等字段；切换不清空已填写内容。保存后刷新组织树和右侧列表。

## 用户新增与编辑

选择组织后，右侧用户列表使用原有“新增”“编辑”按钮，默认进入简要表单：用户名称、登录账号、用户类型、用户类别及角色。登录账号填写邮箱时提交到 `email`，填写中国大陆手机号时提交到 `telephone`，其它普通账号提交到 `loginName`；疑似邮箱或手机号但格式不合格时提示修正，不作为登录名保存。编辑时以现有登录名、邮箱、手机号依次选取一个作为简要回显；更换此登录标识不会清除未选中的其它登录方式。若改用的邮箱或手机号字段已有不同值，简要保存会拒绝；点击“更多”可进入完整表单，原有标识保持不变，由用户明确修改。

新建用户时，平台操作者可在简要表单选择归属租户，并须从该租户的授权组织中重新选择所属组织；切换租户会清空原组织。非平台操作者的租户由当前授权身份与选中组织确定。编辑用户不提供租户切换，已有角色和数据权限范围不因新建流程而改变。

角色由用户资料保存成功后通过独立接口分配。若角色分配失败，页面明确提示“用户资料已保存，角色未分配”，此时从列表的“分配角色”操作对现有用户重试，**不要再次点击新增**。无分配角色权限时简要表单不显示角色控件；用户资料仍受原有组织、租户及接口授权约束。普通资料保存不等于角色已完成分配。

## 结果与最小验证

新增后确认组织树或用户列表出现目标；编辑后重新打开详情核对组织类别、类型或用户登录字段。分配角色后重新打开角色弹窗核对已选角色。简要表单只改变前端填写视图，不新增匿名入口，不改变后端鉴权、租户范围或业务校验。当前通用的向导模式及展示设置五态选择仍按 OpenSpec 后续任务实施，不能把本页简要表单视为这些公共能力已经上线。
