# 快捷添加客户与伙伴使用指南

## 入口与前置条件

在管理端“客户&伙伴”分组的“客户”“供应伙伴”“渠道伙伴”列表页，点击“快捷添加”。操作人须有对应页面的“快捷添加”接口权限，并能管理当前租户的内部父组织；主体搜索另需“工商信息查询”的搜索和详情权限以及已启用的企查查配置。没有工商查询权限或供应商不可用时仍可人工填写主体资料。

## 操作步骤

1. 输入至少两个字符的主体名称，停顿约 0.8 秒后自动调用企查查候选搜索，也可点击“搜索”重试；该供应商调用可能计费。从最多五条候选中选一条，选中后才发起一次工商详情查询，不自动逐条查询候选。查询结果会回填主体名称和18位统一社会信用代码。查询失败、无结果或资料不完整时，直接人工填写或补齐这两项。选择主体类型：法人、个体户或非法人组织；自然人不走此18位代码入口。桌面宽度下主体名称和简称在同一行。
2. 填写简称和管理员手机号。管理员姓名可留空，留空时保存为“管理员”；用户名可留空，系统会生成租户内唯一的“管理员_”前缀登录名，并在成功后显示。密码可留空；留空时该账号不获得可用的初始密码，须使用现有短信验证码登录入口。手机号需由操作人确认，工商资料中的法定代表人姓名不能证明手机号归属。
3. 供应伙伴或渠道伙伴还需选择一项对应业务类型。客户快捷添加固定创建直接客户。点击“确认添加”，成功后当前列表刷新。

## 结果与错误

后端在单个事务中先创建或复用法律主体，再创建外部组织、管理员用户及对应客户或伙伴主档，并写入关联。客户、供应伙伴和渠道伙伴管理员分别获得 `R_CUSTOMER_ADMIN`、`R_SUPPLIER_PARTNER_ADMIN`、`R_CHANNEL_PARTNER_ADMIN`；这三项是启动时初始化、由所有租户共享的全局角色定义，账号的数据范围仍限当前租户及自身组织，原有 `R_CUSTOMER` 不变。相同证件号的本租户法律主体在名称、主体类型一致时会被复用；同一主体已有相同业务身份、手机号或手填用户名已占用、固定角色缺失或权限不足时，整单失败，不保留本次部分记录。人工填写的资料只作为待校验输入，不表示已由工商供应商核验；工商查询也不会自动改变法律主体认证状态。

最小验证：以有权账号分别完成查询命中与人工补录路径，涵盖法人和个体户，核对列表刷新、主体类型、实际用户名、管理员默认姓名及四类关联；再次对同一主体添加同类型关系应失败且记录数不变。密码留空的测试账号应仅能按现有短信验证码流程登录。
