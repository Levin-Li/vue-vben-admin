# 服务插件供应商选择模式接入指南

本包的“服务插件设置”和“租户插件设置”页面从 `ServicePlugin/providerSelectionModes` 取得插件代码声明的 `SINGLE_ACTIVE` 或 `MULTI_CHOICE`。接口需要服务插件查询列表权限；失败时配置写入入口应保持禁用，不按插件名称或编码猜测模式。每个 `ServicePluginSetting` 记录只属于一个供应商，`value` 只保留该供应商的 `value[code]` 配置键。

单选插件可保留多个供应商设置，但同一作用域只允许一个启用；多选插件可同时启用多条。列表每行、租户设置每张卡显示该记录的真实供应商名。每个配置弹窗只编辑当前行，保存仅更新该行 `value[code]` 并携带其乐观锁，不提交其它供应商记录。配置指南默认隐藏，打开后仅覆盖在当前配置弹窗右侧；目录禁用的供应商不可运行，但历史参数不应被清空。

第三方 OAuth 登录页和个人中心绑定页已按服务端平台列表展示多项，并将用户实际选择的稳定编码传给授权接口。中文展示名与协议编码分离；选择框支持中文名和编码搜索。支付通道沿用支付业务模型，不通过此页面维护。

最小验证：在测试作用域创建并启用两条 OAuth 供应商记录，刷新登录与绑定页，核对两个入口都出现且各自授权请求携带自己的编码；分别编辑两行，核对另一行值未改变。对单选插件核对唯一启用者被调用、零启用不可用、异常双启用不随机选择。配置权限、租户/域名范围、服务端模式校验及密钥引用名约束始终由后端负责。
