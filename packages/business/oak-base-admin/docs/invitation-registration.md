# 邀请链接使用指南

> 外部邀请成功后，会在目标组织下创建外部子组织并建立对应客户或伙伴关系。详细规则见[外部组织主档管理页面使用指南](external-org-master-ownership.md)。

## 入口与前提

有相应目标签发权限的后台用户进入“用户&权限 → 邀请链接”。创建入口按标准 CRUD 的 API 权限显示，页面不常驻展示签发资格信息。平台用户先选择自己有权访问的租户，再选择该租户内有权访问的启用内部组织；租户用户使用自己的租户，并选择有权访问的组织。即使账号没有默认组织，只要有可选组织也可签发。服务端在提交和兑换时重新校验租户、组织及签发权限。目标租户登录配置中的“邀请注册”须开启；它与普通自注册开关独立。普通自注册只接受手机号或邮箱，创建的账号不加入组织。

## 创建链接

1. 点击内部用户、会员用户、客户、供应伙伴或渠道伙伴对应的标准签发动作。这些入口采用各 API 的 `@CRUD.Op` 声明并复用公共 CRUD 表单，不再通过工具栏目标下拉切换泛化新增接口；打开后弹窗标题写明邀请目标，本次目标和提交接口固定；供应伙伴、渠道伙伴类型以中文显示，提交仍使用后端枚举常量。客户和伙伴固定为每位注册者新建外部子组织；内部及会员可选加入所选目标组织或每人新建子组织。
2. 平台用户先选择“归属租户”，再在“邀请到哪个组织”选择目标组织；租户用户直接选择组织。切换租户会清除原组织、渠道伙伴及类别选择。内部邀请可按权限选择普通员工或管理员，并可加入现有组织或新建子组织；会员邀请只允许普通身份。外部客户或伙伴邀请可按权限选择普通用户或管理员，固定创建子组织；邀请管理员需要签发人的相应附加权限。客户选择直接客户或渠道客户；供应和渠道伙伴选择具体业务类型。
3. 客户、供应伙伴和渠道伙伴邀请可选择“组织类别”和“用户类型”。两者分别来自所选租户的组织类别和用户类型字典，可留空；选定后写入邀请配置，注册成功时分别用于新组织和新账号。账号身份决定角色，与字典用户类型是两个不同字段。选中的字典值在兑换时会再次校验。
4. 选择允许的注册方式、可留空的到期日期，以及单次、限定人数或不限人数；留空表示永不过期，填写时今天至未来 365 天有效且到期当天仍可使用。限定人数须为 1 到 10000 的整数，单次/不限人数不填写人数上限。签发后这些策略不可修改，也不能删除链接。
5. 创建完成后在结果弹窗复制链接；关闭弹窗后，完整链接不留在列表区域。列表显示目标组织名称，日后可通过列表分页翻看较早签发的链接，再次点击“复制链接”；系统会重新授权并从服务端取得完整地址。列表本身只显示摘要。

查询栏可按邀请目标、账号身份、注册方式、使用次数和到期时间范围筛选；具有创建权限的平台用户还可按归属租户筛选。到期日期用一个起止日期范围组件，分别提交 `expiresAfter` 和 `expiresBefore`；列表行可查看授权范围内的详情。

签发人由服务端确认；平台用户选择的租户和目标组织均须通过服务端授权，租户用户不能通过请求更换自己的租户。客户、供应伙伴、渠道伙伴分别使用对应 `R_CUSTOMER_ADMIN` / `R_CUSTOMER_STAFF`、`R_SUPPLIER_PARTNER_ADMIN` / `R_SUPPLIER_PARTNER_STAFF`、`R_CHANNEL_PARTNER_ADMIN` / `R_CHANNEL_PARTNER_STAFF` 角色，具体按账号身份选择。管理人员可输入原因作废链接；作废保留审计事实。

内部邀请管理员使用组织管理员角色 `R_ORG_ADMIN`，显示该选项需要“邀请组织管理员”权限；外部邀请管理员使用对应伙伴或客户管理员角色，显示该选项需要“邀请子组织管理员”权限。两项权限各自生效，服务端仍会检查目标角色授权范围。

本次升级不保留旧邀请链接的使用兼容。上线前签发的链接需要重新创建；历史记录予以保留，系统不会在普通请求或启动时自动删除或改写。

资格、日期、人数或组织模式不满足时，保存显示对应的安全业务原因；请求层已经提示的错误不会再追加泛化“保存失败”，草稿保留便于修正。后端仍重新检查真实账号、组织及授权，页面打开不代表任意账号都可签发。

## 受邀人注册

受邀人打开链接后，页面先向服务端核验链接，再展示邀请目标和允许的注册方式；公开页面不显示内部目标组织标识或名称。手机号须使用短信验证码，邮箱须使用邮件验证码。外部组织注册还需填写新组织名称、法律主体名称和统一社会信用代码；同租户已存在该身份标识时，注册会被拒绝并提示联系管理员。后台用户注册成功后可前往后台登录；本期会员只完成注册，不自动登录，后续由所属客户端提供会员登录入口，本管理后台 `/auth/login` 不是会员登录入口。会员通过第三方邀请注册时，还需验证手机号或邮箱并设置登录密码。

链接签名错误、到期、作废、名额已满或租户关闭邀请注册时，页面不显示可提交表单，也不会降级为普通自注册。

## 验证方法

在测试租户分别创建单次和限额链接，用新手机号或邮箱完成一次注册，确认账号与组织归属；再次兑换单次链接应失败。作废后应拒绝预览和兑换。仅普通自注册关闭而邀请注册开启时，有效邀请仍应可用。生产环境还需验证短信／邮件供应商配置和第三方认证回调。

对创建入口，应使用具备有效租户和目标组织访问权限的测试账号，从对应目标动作打开表单，选择一个有权访问的目标组织，填写日期及人数后实际点击保存；确认成功后出现链接结果，拒绝时保留草稿且只提示一次。另检查无默认组织但有授权组织的账号可签发、越权/跨租户/停用组织拒绝，过去/超过边界的日期、人数越界和管理员模式冲突均被拒绝。仅打开列表或表单不等于保存链路通过。
