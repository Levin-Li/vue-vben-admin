# 结算单多方页面设计

页面以三组信息组织创建与详情：合作关系及付款/收款方、付款方销售与财务负责组织和人员、收款方组织与对接人、结算时间金额及业务内容。付款方和收款方必须由用户明确选择，不能按伙伴类型或页面当前筛选条件推断。负责人可为空；创建后身份与归属只读。

列表和查询显示多方参与信息，但收款账户、开票资料、发票和付款明细、结算 JSON 与日志仍通过受授权财务详情独立读取。流程动作由服务端支持事件、接口权限和当前状态共同决定。页面只改善输入与展示，服务端负责最终授权和校验。

结算内容继续使用整对象 JSON 编辑器；付款凭证仍由文件资源上传并向登记动作提交资源 ID。旧记录无法确认资金方向时不能在页面静默补全或改写。
