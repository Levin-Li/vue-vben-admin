# 数据脱敏设置页面

## 入口与前置条件

安装并启用 `@levin/oak-base-admin` 后，平台超级管理员在“基础&设置”分组进入页面。页面调用后端 `DataMaskingSetting` 的列表、新增、详情、更新、删除接口和受限实体字段目录；目录读取失败时不能选择新规则字段。

## 配置步骤

1. 新建设置并填写名称、租户、域名、组织类别/类型和用户类别/类型。留空的匹配条件由后端按公共配置语义处理。
2. 在“字段规则”中添加一个或多个实体，为每个实体选择字段及“隐藏”“普通遮盖”或“可还原 ID”。新增快捷填写包含必填的字段规则。目录优先展示中文名称，同时保留技术标识；没有中文标题的实体主键显示为“标识”。仅明确映射到实体字段的请求和响应会按规则处理；其他字段不参与。
3. “可还原 ID”默认绑定当前登录会话、没有额外的令牌超时，也可选择绑定当前用户并填写有效秒数；留空表示无额外的时间限制。绑定会话时，会话失效后令牌不可继续使用。无需选择接口；相同实体字段在有明确映射的请求中可回传该令牌，业务接口仍独立校验操作和记录权限。保存后以目标用户验证响应和回传请求；设置了有效期的令牌过期或主体不匹配时应被后端拒绝。

已登记为图片类型及复杂对象等暂不支持的字段以灰色显示，并标注原因，不能加入规则；已选字段可取消勾选。图片识别依赖已登记的可靠类型元数据，未声明或未登记为图片的普通字符串无法自动区分。宽屏下字段按两列排列；单个字段的处理方式、绑定范围和有效期保持一行，空间不足时可横向滚动。

页面只提交服务端注册目录中的实体和字段；前端展示及勾选不能代替后端的配置校验、接口授权或记录级数据范围校验。加密密钥由服务端管理，不写入配置值。

平台用户可在查询面板选择有权访问的租户，列表的“归属租户”从当前记录的租户 ID/名称回显，新增表单也提供有权访问的租户候选；租户用户的租户由服务端上下文限定，不提供跨租户选择。本模型只有组织类别和组织类型等匹配条件，没有组织归属 `orgId`，因此页面不提供伪造的组织 ID 筛选或列。列表为空时显示“暂无数据”，不能据此判断已有记录的归属值是否回显。

旧规则和旧令牌不兼容、不自动转换或删除。旧规则会提示重新配置，管理员须先按实际环境的备份与变更流程处理原记录，再在本页面重新添加字段；部署前应安排旧令牌的失效影响。
