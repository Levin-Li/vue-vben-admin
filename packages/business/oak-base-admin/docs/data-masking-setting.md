# 数据脱敏设置页面

## 入口与前置条件

安装并启用 `@levin/oak-base-admin` 后，具有“数据脱敏设置”管理权限的人员在“基础&设置”分组进入页面。页面调用后端 `DataMaskingSetting` 的列表、新增、详情、更新、删除接口，以及仅供平台超级管理员读取的实体字段目录和可还原 ID 输入接口目录。目录读取失败时不能选择新规则字段。

## 配置步骤

1. 新建设置并填写名称、租户、域名、组织类别/类型和用户类别/类型。留空的匹配条件由后端按公共配置语义处理。
2. 在“字段规则”中添加一个或多个实体，为每个实体选择字段及“隐藏”“普通遮盖”或“可还原 ID”。保存前核对页面列出的实际覆盖接口；不能明确映射的接口不会自动生效。
3. “可还原 ID”还须选择接收 ID 的输入接口与请求字段，并设置绑定当前用户或当前会话、有效秒数。保存后以目标用户登录，验证响应和回传请求；过期或主体不匹配应被后端拒绝。

页面只提交服务端注册目录中的实体和字段；前端展示及勾选不能代替后端的配置校验、接口授权或记录级数据范围校验。加密密钥由服务端管理，不写入配置值。

旧按接口配置不在页面中自动转换；版本升级时先按发布迁移删除并备份，再在本页面按实体重新配置。
