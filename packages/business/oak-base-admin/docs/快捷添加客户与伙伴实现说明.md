# 快捷添加客户与伙伴实现说明

## 模块落点

客户、供应伙伴和渠道伙伴页面分别在 `views/customer/index.vue`、`views/supplier-partner/index.vue`、`views/channel-partner/index.vue` 接入共用的 `views/partner/quick-add.vue`。三个页面仍使用原业务分组与列表，成功后只刷新当前列表。各页面 `config.ts` 登记稳定的 `listOperations` 键，使“快捷添加”参加列表操作设置；权限以对应 API service 的 `quickAdd` 方法为准。

`api/quick-partner-onboarding.ts` 声明请求和结果类型，三个业务 API service 分别请求 `/Customer/quickAdd`、`/SupplierPartner/quickAdd`、`/ChannelPartner/quickAdd`。`api/business-registry-service.ts` 封装 `/BusinessRegistry/use/search` 与 `/BusinessRegistry/use/lookup`，供弹窗辅助录入。

## 提交与状态处理

弹窗打开时清空上一次账号、候选和来源状态。主体名称输入至少两个字符后防抖搜索；请求代次用于丢弃过期响应。选中候选才调用详情。人工修改登记名称或代码时，来源改为人工，页面不会把修改后的值显示成已由供应商核验。

提交前检查主体名称、18 位代码、简称、管理员手机号和适用的伙伴子类型。`subjectType` 只提交 `Legal`、`Individual`、`NotLegal`；`adminName`、`loginName`、`password` 留空时不提交。接口成功后展示返回的实际 `loginName`，关闭弹窗并刷新原列表；业务拒绝保留草稿供修正。按钮与请求均使用既有 RBAC 能力，前端校验和隐藏不替代后端授权或事务校验。

## 运行与限制

宿主应用需已注册 Oak 模块并能访问三个既有业务路由；真实菜单仍由后端授权决定。工商候选搜索需要单独开通企查查配置及搜索、详情权限，可能产生供应商费用；配置缺失时可人工补录。短信登录需要租户已有短信通道，页面不会验证手机号归属。后端事务、同主体复用、角色初始化与错误语义见包内[使用指南](快捷添加客户与伙伴使用指南.md)及后端公开接口文档。
