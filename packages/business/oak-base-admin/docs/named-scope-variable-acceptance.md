# 具名数据范围变量验收与使用说明

`@levin/oak-base-admin` 提供领域、租户、组织和拥有者上下文的页面注册与 API 映射。正式业务接口必须使用自身 DTO 和授权模型；本说明中的专项验收能力仅用于非生产环境。

## 页面

本地开发环境可访问：

```text
/clob/V1/namedScopeVariableAcceptance
```

页面可分别提交显式租户、领域、组织、组织列表、拥有者和拥有者列表，并展示原始参数、收到的范围 Header 与服务端最终解析值。它用于确认“显式参数优先、空值 Header 回退、单多选互斥和越权拒绝”。

## 非生产验收接口

基础路径：

```text
/com.levin.oak.base/V1/api/namedScopeVariableAcceptance
```

| 接口 | 用途 |
| --- | --- |
| `POST /echo` | 回显显式值、范围 Header 和具名变量最终解析值。 |
| `GET /articleIds` | 通过现有 Article 业务服务返回当前主体实际可见的文章 ID。 |
| `GET /accessibleArticleScopeContext` | 只读诊断当前主体的文章组织/租户范围和机密访问级别。 |

这些入口要求认证且仅在 local、dev、test 环境装配；生产环境不会注册。它们不执行业务写入，不能作为正式业务 API 依赖。

## 后端集成要求

- 使用 `@InjectVar` 声明范围字段，由服务端解析 Header 和显式参数。
- 对组织、拥有者等 ID 逐项执行存在性、租户、组织、领域与机密等级校验。
- 业务列表或详情必须调用自身业务服务的数据范围查询，不能只依赖管理页面候选列表。
- Article 类业务服务会同时追加组织、租户和机密等级谓词；直接服务调用也会填入已验证组织集合，避免生成请求对象的安全兜底误拒绝。
