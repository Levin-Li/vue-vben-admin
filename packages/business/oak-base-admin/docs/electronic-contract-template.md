# 两方电子合同模板使用指南

管理端进入“电子合同模板”，使用标准 CRUD 查询和列表。点击“新增”，在表单中填写模板编号、名称和类别，上传 `.docx` 模板，并配置变量定义。文档中的纯文本占位符写为 `{{变量名}}`；变量清单是 JSON 数组，例如 `[ { "key": "customerName", "title": "客户名称", "required": true } ]`。上传接口登记受控文件资源，表单自动带入资源 ID、文件名、路径、哈希和类型；这些技术字段无需人工填写。管理员代填归属时，上传与保存须使用同一租户、组织和所有者，改变归属后需重新上传；未填写所有者时服务端使用当前操作者。保存后回到列表核对草稿，通过行操作上线；已上线模板通过行操作归档，删除入口关闭。

进入“电子合同”后使用标准 CRUD 查询和列表。点击列表工具栏“新增”，在标准新增表单中选择已上线模板、甲方本方法律主体和乙方客户、供应伙伴或渠道伙伴，填写合同号、名称及模板变量后保存；系统通过受控接口生成合同独立文件。创建后回到列表查看合同详情，按当前状态执行有权限的签署操作。模板来源合同不得通过普通编辑改变模板、双方或变量；需要重新生成时使用受控的重新生成接口。具有独立“领取签署入口”权限的管理员可按甲乙双方分别领取入口；普通查看详情权限不能领取。当前仅支持两方合同，签署地址按次领取，不写入合同列表或详情。模拟回调和签章位置调试不属于日常电子合同页面。

变量名和取值由后端按模板声明校验，文件由后端独立生成和冻结。缺少模板、主体或必填变量时保存失败并显示错误；跨租户或无权使用的资源、主体和合同由服务端拒绝。可用最小验证：创建带一个必填变量的模板并上线，从电子合同 CRUD 新增表单选双方生成草稿，再从列表查看合同并提交签署。
