# 两方电子合同模板使用指南

管理端进入“电子合同模板”，先上传 `.docx` 模板。文档中的纯文本占位符写为 `{{变量名}}`；变量清单填写 JSON 数组，例如 `[ { "key": "customerName", "title": "客户名称", "required": true } ]`。上传接口会登记受控文件资源，保存模板时带入服务端返回的资源 ID、文件名、路径、哈希和类型。管理员代填归属时，上传与保存须使用同一租户、组织和所有者；未填写所有者时服务端使用当前操作者。模板草稿核对后在列表中上线；已上线模板通过归档退出，删除入口关闭。

进入“电子合同”，点击“加载可用模板和签约主体”，选择已上线模板、甲方本方法律主体，以及乙方客户、供应伙伴或渠道伙伴。列表可逐页加载更多候选。填写合同号、名称和模板变量后生成合同文件。页面显示受控原文预览；草稿阶段修改变量或双方后点击“重新生成待签文件”，再次预览确认后提交签署。具有独立“领取签署入口”权限的管理员可分别领取甲乙双方入口；普通查看详情权限不能领取。当前仅支持两方合同，签署地址按次领取，不写入合同列表或详情。

变量名和取值由后端按模板声明校验，文件由后端独立生成和冻结。缺少模板、主体或必填变量时页面会提示；跨租户或无权使用的资源、主体和合同由服务端拒绝。可用最小验证：创建带一个必填变量的模板、上线、选双方生成草稿、确认预览后提交签署，分别领取两个入口。
