# 基础模块 AI 业务与故障诊断使用指南

## 入口与前置条件

登录管理后台后，从页面右下角“系统 AI”打开聊天窗。需要启用基础业务模块和一个 AI 服务插件，并由管理员在“服务插件设置管理”保存当前租户/域名的网页配置。网页 Agent 仅通过 `GET /com.levin.oak.base/V1/api/client/ai/chat/browser-config` 读取已保存设置，然后由 AI SDK 模型客户端通过受控原生 fetch 直接请求供应商，不使用后台聊天中转。ChatGPT 对应 OpenAI API 模型，API 计费与 ChatGPT 网页订阅分开。网页接入包括 OpenAI、DeepSeek、GLM、Kimi、MiniMax；Claude Code 是 CLI 运行时，不能在纯网页运行，已有后端适配不属于本网页能力。

管理员须显式开启默认关闭的 `browserDirectEnabled`，提供独立 `browserApiKey`，并按需设置 `browserBaseUrl`；为空时使用供应商 Base URL，最终必须为 HTTPS。后端代码继续使用独立 `apiKey`，其值不会由网页配置接口发放。模型列表只显示当前作用域完整且启用网页直连的设置，默认选中首个可用项；多选模式可切换本次供应商。旧单选配置切换模式前须由管理员逐条重存，使 `enable` 和 `enabled` 都为 `true`，系统不会自动迁移。

开启网页直连即授权当前租户登录用户取得独立网页凭证，它对浏览器用户可见。请在供应商限制额度、模型与可用范围，制定撤销策略。网页凭证只留内存，配置响应禁止缓存，不写消息、日志或浏览器持久存储。身份、租户、组织或域变化会清理旧会话与待执行操作，并重新读取配置。

无租户的平台超级管理员或平台管理员使用明确启用的全局网页配置；页面显示默认租户品牌不会改变这一全局身份，也不会读取该页面租户密钥。普通平台用户不获得全局凭证。网页配置接口实际由 `admin-api` 提供，管理后端必须包含该模块；无需引入全部客户端接口。

网页凭证按最终配置记录的真实归属发放，不自动继承其它租户或平台的网页密钥；租户需要保存自身网页配置。后端模型服务原有公共配置继承规则保持不变。

供应商必须允许当前页面来源的 CORS，页面 CSP 必须允许连接供应商；不满足时显示明确错误，不回退后台代理。模型请求不携带系统 Token/Cookie、不跟随重定向，限制超时和响应大小。前端限制不能提供可靠服务端配额或完整模型审计；后台“测试连接”仅验证后端凭证和后端网络，不能证明网页凭证与 CORS 可用。

## AI SDK 与费用

本业务包正式使用 `ai@6.0.309` 和官方 `@ai-sdk/openai-compatible@2.0.85`，以 `generateText` 和 `createOpenAICompatible` 调用已配置供应商。[AI SDK 按 Apache-2.0 免费开源](https://github.com/vercel/ai/blob/main/LICENSE)，使用 SDK 无需购买授权；模型 API 用量仍由供应商计费。本直连方案不使用默认 AI Gateway，不需要 Vercel 账号或托管服务。

[SDK 官方能力](https://ai-sdk.dev/docs/introduction)包括文本与流式生成、结构化输出、工具调用、Agent 循环/审批，以及取决于供应商的多模态、嵌入等。本次实际采用文本模型客户端，保持现有最多 8 步的业务编排与 88 项受控技能，没有接入 `ToolLoopAgent`，未因此增加流式聊天 UI、图片生成或 RAG。供应商由[官方兼容适配器](https://ai-sdk.dev/providers/openai-compatible-providers)接入，模型对象显式绑定网页配置；自动重试设为 0、遥测关闭，保留取消、超时、输入输出边界与错误脱敏。

## 已登记业务技能

AI SDK 依赖固定在兼容项目现有 Node >=20.19 基线的稳定版本，构建不要求升级至 Node 22；浏览器用户无需安装 Node。供应商跨域和网页凭证额度要求保持不变。

主要业务按以下目录显式接入；目录按当前用户的 API 权限筛选，能查询的字段仍受原接口的数据范围与字段授权限制。通常每页最多 20 条、最多查询第 5 页；跨业务分析受整个任务的记录与上下文预算限制，不能把分页样本当作全库统计。

| 业务范围 | 查询与分析 | 可确认处理 | 当前未开放动作 |
| --- | --- | --- | --- |
| 客户、法律主体、伙伴、供应商、渠道、组织 | 列表与单条运营摘要、类型、等级、分组、启用状态及关系 ID | 客户、供应商和渠道伙伴的等级、分组、启用字段修改 | 主体认证、身份/银行资料、归属及权限修改；通用伙伴无专用更新接口，仅查询 |
| 支付订单、资金账户及流水、结算单 | 有权台账的状态、金额、币种、业务关联与日期 | 无 | 付款、退款、对账、供应商查单与资金操作 |
| 发票、合同、合同模板 | 单据状态、金额或业务关联、日期和模板摘要 | 无 | 开票、红冲、签署、提交、撤销、下载原件 |
| 资讯、栏目、公告、页面、表单 | 标题、状态、分类和时间摘要 | 无 | 正文读取、编辑、审批、发布、下线及执行表单接口 |
| 品牌、字典、站点、域名 | 基本目录与启用/生命周期状态 | 无 | 原始配置、密钥、DNS/证书申请或续费 |
| 流程申请、定义、报销、个人流程及实例管理 | 申请摘要；定义列表；报销详情；待办/已办/发起/抄送；任务及实例状态，管理查询另需权限 | 无 | 发起、审批、办理、终止、恢复、重试及原始表单/时间线 |
| 工单、受理队列、受理邮箱规则、个人消息、投递审计 | 工单状态、优先级、队列；规则启用状态；本人消息目录和未读数；投递状态及有限尝试摘要 | 工单队列和受理邮箱规则启停 | 对外发送、消息正文、标记已读、原始邮件和投递重试 |
| 调度任务与调度日志 | 任务名称、启用状态、执行次数、日志时间和错误标记 | 无 | 脚本、执行快照、运行结果、手工执行或调度修改 |
| 用户、角色、租户、服务插件及插件设置 | 有权限的账号状态、角色/租户目录、插件和供应商配置存在及启用元数据 | 无 | 密码、令牌、密钥、联系方式、权限列表、配置值和任何权限/凭证维护 |

可以说“查询未支付订单并按币种分析当前样本”“查客户 customer-1 的等级和分组”“修改客户 customer-1 的分组为重点客户”“查询我收到的流程待办和未读消息数量”。需要取数时模型选择已登记技能；缺少定位或范围时在聊天中补充，不要求进入菜单填表。范围不明时不可臆造 ID。

普通修改只变更明确提供的字段。Agent 先读取当前状态与版本，在聊天里展示差异，收到“确认”后再次核验权限、范围和版本，调用原接口并读回；核验成功后可继续原任务。提交或核验结果不确定时不会重复提交；输入“复查”只读核对，输入“取消”结束跟踪。启停规则会影响后续工单受理，必须核对预览。

代码按[客户及关系](../src/modules/com_levin_oak_base/agent-customer-skills.ts)、[财务及合同台账](../src/modules/com_levin_oak_base/agent-finance-skills.ts)、[内容站点与调度](../src/modules/com_levin_oak_base/agent-content-skills.ts)、[流程](../src/modules/com_levin_oak_base/agent-workflow-skills.ts)、[消息及受理规则](../src/modules/com_levin_oak_base/agent-message-skills.ts)、[管理目录](../src/modules/com_levin_oak_base/agent-admin-skills.ts)维护；共用[参数与投影边界](../src/modules/com_levin_oak_base/agent-business-common.ts)，原[工单与诊断技能](../src/modules/com_levin_oak_base/agent-skills.ts)保持独立。

模型只看到登记的技能定义；未登记的业务动作、删除、批量修改、审批、资金、权限和对外发送不会由本助手执行。业务 API 仍按当前登录用户的功能权限、租户、组织、数据范围和业务状态判断，模型不能替用户扩大权限。

## 后端故障诊断

只有超级管理员可以使用访问日志异常摘要和固定来源 ERROR 文件证据技能。可在聊天中要求“分析今天的后端异常”；Agent 在不超过 24 小时的时间窗内查询有界、脱敏的证据，按异常类型和应用方法归并，区分已证实事实、根因推断和下一步验证。访问日志只保存异常类型，单靠它不能证明根因；ERROR 文件证据也不包含原始错误消息、请求体或完整堆栈。证据不足时应继续缩小时间或定位跟踪标识。

服务端只读取固定的 `logs/YYYY-MM-DD/error-log.N.log[.gz]`，不接受浏览器文件路径；限制文件数、压缩与解压字节及输出大小。达到 HTTP 压缩阈值时服务端使用 GZIP，浏览器自动解压。诊断只给出建议，不会自动执行代码修改、生产重启、部署、数据库迁移或脚本。

## 结果与最小验证

普通聊天回复不代表系统已执行操作。查询结果会标注数据来源与条数；业务写入只有在接口成功且后置查询一致时才报告完成。供应商未配置、密钥失效、权限不足、范围不明确、参数超限或版本冲突都会返回明确失败信息。

使用测试账号验证：普通用户只能看到自身授权业务结果且无法调用诊断；超级管理员可查询脱敏诊断数据；让 Agent 查询队列、预览启停、输入“确认”后核对队列状态；切换页面后聊天保留，退出后内容清空。在浏览器 Network 确认模型请求直达供应商 HTTPS 地址，不包含系统认证，失败时无本系统 `chat`/`stream` 回退；检查配置 `no-store`、作用域清理及未持久保存凭证。真实供应商 CORS/CSP、网页凭证额度和生产日志目录需在对应部署环境另行验收。
