# 组织职能使用指南

在“机构管理”页面的组织信息中，可为组织选择一个可选的主职能，也可在列表中查看或按职能筛选。选项来自后端字典 `com.levin.oak.base.entities.Org.responsibilityCode`；管理员在“字典管理”中维护公共或租户选项。

首次安装后，后端预置销售、市场、渠道管理、研发、设计、测试、质量管理、质量检验等常见选项。渠道管理不固定归属市场或销售。一个部门没有适用的主职能时可以留空。保存后重新打开组织，确认职能名称正确回显；如选项缺失，检查字典编码、启用状态和当前租户。

组织职能只描述部门工作，不自动改变组织类型、父级、岗位、负责人、角色或数据权限。操作机构与字典仍需要相应的管理权限；组织保存失败时还应检查该记录是否在当前用户的数据范围内。
