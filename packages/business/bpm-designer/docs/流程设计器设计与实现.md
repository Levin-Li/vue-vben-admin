# 流程设计器设计与实现

## 目标与边界

设计器将业务能力目录中的字段、条件和操作组合成版本化流程定义。业务对象只需公开受控能力，不要求继承流程实体或存在固定状态字段。一个用途表示一个独立业务阶段，多个用途可通过同对象、同轮次、已应用的前置结果衔接。

设计器不执行 JavaScript、SQL、SpEL 或脚本，不访问任意数据库表。业务归属、权限、真实人员解析、事务和最终结果写入由服务端负责。

## 配置事实源

新版本的唯一可编辑配置是 `lowflowDefinition` 中的 `schemaVersion: 3` 和受限 `flowTree`；`processKey`、`name`、`purposeKey`、`businessBinding`、`variables`、`startPolicy`、可选 `dependencies`、`outcomeActions` 与 `simulationPolicy` 同属版本配置。根级 `nodes/edges` 只在服务端从树确定性投影，客户端不提交第二份可编辑图。节点位置 `x/y` 仅用于画布展示。服务端拒绝未知执行键。

业务能力目录采用 `businessType + contractVersion` 标识。`fields`、`actions`、`validators` 是以公开标识为键的对象映射；用户可见名称为 `title`。字段类型、允许展示/判断/编辑及敏感等级直接来自目录。

条件为 `all/any/not` 组合、类型比较或 `dependency/validator` 叶子。变量引用为 `{variable:"name"}`，常量为 `{literal:value}`。业务动作和校验器参数也必须使用这种显式来源，不能提交裸值。自动启动采用 `startPolicy.events` 和 `servicePrincipal`，事件必须已由业务模块接入。

## 组件分工

- `WorkflowDesigner`：不可变 v-model 编辑，基本信息、业务适配、启动依赖、图、节点、结果操作及只读配置预览。
- `WorkflowConditionEditor`：递归条件树，布尔和数值保持类型，依赖固定当前轮次与已应用结果。
- `WorkflowParameterEditor`：从能力目录选择固定参数或同类型流程变量，供只读校验器和结果动作复用。
- `WorkflowDefinitionWorkbench`：加载能力目录，保存、模拟、发布与错误提示；宿主提供实际接口派生的权限。
- `WorkflowDesignerService`：唯一设计期网络入口；界面组件不直接使用通用请求客户端。
- `definition-model`：v3 新建树、严格执行前本地校验；旧 v2 平面模型仅供显式迁移转换测试。
- `workflow-tree-edit`：按稳定 ID 原子插入审批/结构化网关或双终局结果出口，删除普通单入单出任务；节点及排他出口属性只写回树。

画布基础直接来自随包保留来源与 MIT 许可证的 [lowflow-design 固定版本源码](../third-party/lowflow-design/ORIGIN.md)。活动 `FlowDesign` 已采用主题语义色、稳定节点/连线标识与无 Element Plus/mock 网络依赖的 Vue 组件。设计期从唯一树投影出画布展示结构，编辑事件回写树；运行组件复用只读画布，只传服务端授权的状态。原上游其它属性面板仍在源码快照中供适配参考，不能把当前局部画布接入表述为所有原生编辑能力已完成。

v3 设计器不调用 `fromLowflowCanvasTree` 反向生成可编辑平面定义；该往返契约只留给显式旧格式转换。草稿树投影保留全部稳定节点、分支和连线 ID；属性按 ID 直接修改原树。草稿与严格执行门禁分离：未补全出口条件可继续保存，但不能模拟或发布。选线新增双终局出口及删除普通单入单出任务使用原子树操作并保留原入边身份；自由连线、游离结束和网关成组删除仍无安全编辑入口，页面明确拒绝并保持原树。后端转换、模拟和发布必须重新投影固定树并校验摘要。

树形适配给分支伪节点附加仅供画布显示的 `branchKind`：排他出口标“条件分支”，并行出口标“并行支路”。这一展示属性由父网关类型确定，不写入固定执行 JSON，也不推导实际经过哪条路线；运行节点完成/跳过状态仍只来自服务端授权历史。

## 状态与并发

Draft 和 Testing 可以编辑；Testing 发生变更后禁止复用旧报告发布。保存携带 `optimisticLock`，成功用完整响应更新版本和定义。失败保留编辑内容，显示服务端错误；请求期间禁止重复动作。Published、Retiring、Retired、Archived 只读。

本地结构校验不构成发布证明。服务端还需验证字段及参数类型、依赖环、人员与数据范围、可执行图及模拟覆盖。只读配置预览不是绕过校验的 JSON 导入入口。

## 图与节点

支持开始、用户任务、排他条件网关、成对并行分叉/汇聚和明确结果的结束节点。并行分叉使用 `joinId` 指向汇聚节点。ALL/ANY 多人审批需至少两名明确用户，不混用候选组。退回配置 `returnTargets`，服务端验证必经前置与并行边界。转办、委派、加签目标资格可单独配置 `actionCandidateUsers/Groups`，实际动作仍由运行模块执行。

节点表单字段分别为 `readableFields/editableFields/requiredFields`。可编辑表单必须绑定 `formAction`，字段必须可读且同时位于业务能力可编辑范围、动作 `writableFields` 及同名同类型参数集合；不支持任意字段赋值或未实现的参数映射。最终结果操作独立于节点审批动作，按配置顺序执行；无结果操作也可只保留平台结果。

在线模拟采用注册期冻结的纯数据 fixture，在线不调用真实适配器的 `load/execute/validate`；声明式校验器由有预算的结构规则解释器执行，代码型回调不作为在线能力。独立 `simulationDigest` 使 fixture 变化后的旧模拟证明失效。该边界正在本批集成，不能把模拟成功解释为已经执行真实业务动作或覆盖所有数据库/外部副作用。完整多业务、并发和失败恢复以对应批次实际验收为准。

接口、配置步骤和最小验证见[使用指南](工作流设计器使用指南.md)，消费方扩展边界见[模块开发规范](MODULE-DEVELOPMENT-STANDARD.md)。发布包仅保留面向使用者的设计/实现/指南和独立开发规范，验收、审计、迁移、日志不随包交付。
