# 运行时使用指南

安装与宿主版本匹配的 `@vben/runtime`，并按所用功能配置 Vue、Vue Router 和 Pinia 等依赖。公开入口包括 `@vben/runtime/access`、`constants`、`hooks`、`icons`、`locales`、`request`、`stores`、`types` 和 `utils`，以及 `plugins/*`、`styles` 等子路径；使用 `package.json` 的 exports 中列出的入口，不依赖内部文件路径。

菜单路由只注册当前用户获授权的页面；目标页面未获授权时，其别名也不会被注册。接口权限和数据范围仍由服务端执行，页面路由可见不代表接口授权。

页面设置可通过 `useTabbarStore().setPageKeepAlive(tabKey, keepAlive, routeDefault)` 控制当前标签缓存；`tabKey` 由公开的 `getTabKey(route)` 取得，`keepAlive` 为 `undefined` 时恢复路由默认值。全局标签缓存关闭时页面仍会重新挂载。

请求失败时，服务端对象响应作为异常抛出；其他失败保留原始请求异常。最小验证是在应用中导入所需公开入口并构建，然后分别以有权和无权账号访问菜单及其别名，确认前者可用、后者受拒绝。

模块扩展、兼容和安全要求见 [模块开发规范](MODULE-DEVELOPMENT-STANDARD.md)。
