# 标签页面缓存

## 入口与前提

`@vben/layouts` 的路由内容容器使用 `@vben/runtime/stores` 的标签缓存名单。宿主须启用标签栏的全局缓存偏好，并让需要缓存的标签进入 `cachedTabs`。业务页可通过路由 `meta.keepAlive: true` 声明默认行为；标准 CRUD 页面也可使用 `@levin/admin-framework` 的页面展示设置覆盖当前标签。

## 运行行为

缓存以路由名称和完整标签 key 区分实例。容器会稳定地将业务组件包装为与路由同名的缓存入口，兼容自带 `index` 等名称及被多个路由复用的页面组件；原业务组件定义不会被改名。全局缓存关闭时直接渲染页面。

手动刷新、关闭标签及全局请求上下文失效仍按标签仓库现有动作清理实例；页面缓存只影响前端生命周期，不修改 API 授权或服务端数据。

## 最小验证

在已启用缓存的标签修改查询条件并翻页，切到另一标签后返回，确认页码与条件仍在且没有额外列表请求。手动刷新当前标签应重新挂载；关闭并重开也应重新加载。若切回仍重载，检查全局缓存偏好、标签 `keepAlive` 标志及缓存名单中是否包含路由名。
