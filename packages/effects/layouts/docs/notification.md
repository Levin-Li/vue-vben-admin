# 顶部通知组件使用说明

通过 `@vben/layouts` 公开入口使用 `Notification`。宿主传入服务端未读总数 `count`、红点 `dot` 和有限预览 `notifications`；预览条数不代表未读总量。

每条提醒包含稳定消息标识、安全标题/摘要、时间、已读状态及可选导航目标。业务集成应使用服务端可信来源类型和固定本地页面产生 `link/query`，不得将外部邮件正文或任意用户输入作为导航地址。通用组件的导航能力不承担来源详情授权。

点击提醒仅导航，保持当前个人已读状态。组件提供独立 `read`、`makeAll`、`clear`、`remove` 和 `viewAll` 事件；宿主必须按业务语义提交有权限的受控接口，并在成功后重新加载计数与预览。不要在点击来源或获取详情时自动调用已读接口，也不要先乐观清空服务端状态。

最小验证：计数超过预览数量仍显示真实总数；点击未读提醒导航而不触发 `read`；显式已读按钮触发对应事件；无权来源由来源页独立拒绝，不能因组件具有链接而取得访问权限。
