## 验证与发布

Oak 页面测试 169 个文件、721 项通过；公共 CRUD 排序、详情与查询回归 103 项通过。Oak 类型检查、改动页面 ESLint、页面清单、CRUD 布局、详情字段契约及 API 资源类型检查通过。Chrome 隔离夹具确认静态基础顺序、审计时间后置及用户展示设置优先；本次未连接完整业务站点登录环境。后端新增机器人接口的静态 API 属性组契约重新导出后，一致性门禁及 13 项测试通过。

首次正式发布在静态字段契约门禁处停止，**没有上传任何 npm 包**。补齐唯一缺失的 `RobotNotifyGroup/sendTest` POST 契约后，第二次标准入口上传了框架/BPM `6.0.31` 与 Oak `6.0.40`；随即本地 tarball 审查发现构建脚本覆盖了框架包 `AGENTS.md` 中的新指南链接。这组已上传版本不是最终推荐版本，也未覆盖已发布内容。修正生成模板并增加实际 tarball 双入口门禁后，最终入口对四包重新完成构建、路由资源、包内文档、精确依赖和独立消费者安装与构建校验，再将新版本的同一份已校验 tarball 上传至 `http://nexus.v-ma.com/repository/npm/`；命令零退出，四包逐个报告发布成功。没有在成功后重复查询或下载私服构件。

本批 tarball 精确核对：框架包包含 `AGENTS.md`、`README.md`、`docs/crud-detail-static-fields.md` 和公共排序源码，且最终版两个入口均直接链接该指南；Oak 包包含 `AGENTS.md`、`README.md`、`docs/robot-notify-group.md`、机器人页面源码及 `data-attr-contract.json`；BPM 两包和 Oak 的 `peerDependencies` 均指向框架 `6.0.32`。新增发布门禁 19 项测试通过。这些文档与源码随包交付；本发布记录只保存在源仓库。
