# 2026-11-15 全页面租户与组织字段补漏发布

## 范围

按根仓库 [逐页矩阵](../../../../openspec/changes/c20261115-0953-crud-tenant-org-field-coverage/page-audit.md) 核对 86 个 Oak 管理路由和 7 个内嵌入口的查询、列表、新增、编辑、详情。数据脱敏设置补充真实 `tenantId` 查询；多个组织实体补齐 `orgIdList` 查询、归属列表和创建字段；专用通知、工单、工作流页面补充接口允许的授权租户级查询。邀请链接查看者改用只读租户候选，列表展示与签发权限分离。公共 CRUD 的查询租户切换会清除旧组织选择，不推断运行时字段，也不覆盖用户已保存的展示设置。

开发期增加租户组织字段静态检查并接入 `check` 与 Oak 发布前门禁；前端页面和查询表单规范增加逐接口五视图核对要求。现有公共选择器、工作台和邀请指南随包交付。地址普通编辑组织改派继续只读；个人设置查询与新增继续限定本人范围。

## 验证与边界

Oak Vitest 230 文件、1290 项通过；公共 CRUD 查询租户联动回归 67 项通过；Oak 类型检查及两个业务包构建通过。页面清单覆盖 86 路由、7 内嵌入口、14 公共框架 URL；布局、API 资源类型、静态属性组 896 接口以及发布包文档门禁通过。新增字段检查覆盖 460 个视图场景，未发现可确定漏配；88 个动态构造或专用接口场景按逐页矩阵人工核对，不能视为自动证明。

本次未在用户当前生产浏览器逐页提交真实业务数据；生产部署与现场验收另见下游项目部署记录。没有新增数据库迁移、外部依赖或运行时字段补全逻辑。
