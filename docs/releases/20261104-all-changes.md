# 2026-11-04 管理前端增量发布

本批将当前后端字段授权声明同步到 Oak 管理端静态契约，并发布 `@levin/oak-base-admin@6.0.30`。此前提交的框架、BPM 设计器和 BPM 运行端版本均为 `6.0.24`，私服已存在这些精确版本，本批没有重复上传。

交付范围包括 `package-versions.json`、Oak 的版本元数据、随包帮助清单与 `data-attr-contract.json`。本地浏览器夹具、临时 tarball 和发布日志不进入提交或包。实际服务部署、生产登录和数据库迁移不由本次 npm 包上传执行。
