# 2026-09-07 主内容区滚动边界修复发布

固定顶栏下的公共主内容容器现在显式允许 flex 收缩，并由自身处理纵向滚动。页面内容未超过可用高度时不会再因页面最小高度、间距或顶栏偏移出现空白滚动条；内容真实超高时仍可在主内容区滚动。主内容区横向溢出保持隐藏，表格继续在自身容器处理横向滚动。

发布依赖闭包和顺序：

1. `@vben-core/layout-ui@5.6.16`
2. `@vben/layouts@5.6.25`（依赖新的 layout-ui）
3. `@levin/admin-framework@5.6.88`（精确 peer 指向新的 layouts）
4. `@levin/oak-base-admin@5.6.90`（精确 peer 指向新的 framework）

四个版本均已从私服回查。验证包括布局滚动边界的 5 个 Vitest 用例、两级构建以及标准发布流程的 tarball、独立安装和私服回查门禁。

下游应用升级这四个版本并重新构建后生效；已部署的静态前端不会自动替换当前运行的旧 bundle。
