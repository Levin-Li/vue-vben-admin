# 2026-09-07 全局组织与用户上下文、注册安全发布

发布 `@levin/admin-framework@5.6.87` 和依赖它的 `@levin/oak-base-admin@5.6.89`。

框架包提供“全局组织与用户选择器”运行时上下文、请求参数覆盖规则及使用说明；认证页按登录选项显示用户注册和第三方登录入口，并支持注册后自动登录。Oak 包仅因精确 peer 依赖更新而级联发布，peer 版本固定为 `@levin/admin-framework@5.6.87`。

发布前标准流程完成两包构建、本地 tarball、独立消费者安装和私服回查 tarball 校验。所有修改的源文件、说明和构建产物均包含在发布包中。此前面向公共镜像的独立安装失败未上传任何构件；改用项目私服后完整流程通过。

本批验证包括 47 个注册、登录和全局上下文聚焦测试，以及真实浏览器注册闭环验证。全仓已有类型检查问题未作为本批发布阻断项；新增类型问题已在包构建中消除。
